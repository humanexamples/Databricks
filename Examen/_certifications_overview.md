# Databricks Certification – Community Übersicht

> Access industry-recognized credentials to validate your expertise in data engineering, analytics, and more.

Quelle: [community.databricks.com/t5/certifications](https://community.databricks.com/t5/certifications/ct-p/databricks-certifications)

---

## Zertifizierungspfade

### Data Analyst

Data analysts transform data into insights by creating queries, data visualizations and dashboards using the Databricks Platform.

| Level | Beschreibung | Link |
|-------|-------------|------|
| **Associate** | The Databricks Certified Data Analyst Associate certification exam assesses an individual's ability to use the Databricks SQL service to manage data and create data objects, run queries and dashboards, and apply basic data governance. | [Learn more](https://www.databricks.com/learn/certification/data-analyst-associate) |

---

### Data Engineer

Data engineers design, develop, test and maintain batch and streaming data pipelines using the Databricks Platform.

| Level | Beschreibung | Link |
|-------|-------------|------|
| **Associate** | The Databricks Certified Data Engineer Associate certification exam assesses an individual's ability to utilise the Databricks Data + AI Platform to execute foundational data engineering tasks. | [Learn more](https://www.databricks.com/learn/certification/data-engineer-associate) |
| **Professional** | The Databricks Certified Data Engineer Professional certification exam assesses an individual's ability to build, optimise, and maintain production-grade data engineering solutions on the Databricks Platform. | [Learn more](https://www.databricks.com/learn/certification/data-engineer-professional) |

---

### ML Data Scientist

Machine learning practitioners develop, deploy, test and maintain machine learning models and pipelines using the Databricks Platform.

| Level | Beschreibung | Link |
|-------|-------------|------|
| **Associate** | The Databricks Certified Machine Learning Associate certification exam assesses an individual's ability to use the Databricks Machine Learning platform to build and manage machine learning workflows. | [Learn more](https://www.databricks.com/learn/certification/machine-learning-associate) |
| **Professional** | The Databricks Certified Machine Learning Professional certification exam assesses an individual's advanced ability to design end-to-end ML solutions on Databricks. | [Learn more](https://www.databricks.com/learn/certification/machine-learning-professional) |

---

### Generative AI Engineer

| Level | Beschreibung | Link |
|-------|-------------|------|
| **Associate** | The Databricks Certified Generative AI Engineer Associate certification exam assesses an individual's ability to design, build and evaluate GenAI solutions on the Databricks Platform. | [Learn more](https://www.databricks.com/learn/certification/genai-engineer-associate) |

---

### Spark Developer

Spark Developers apply the Spark DataFrame API to complete basic data manipulation tasks within a Spark session.

| Level | Beschreibung | Link |
|-------|-------------|------|
| **Associate** | The Databricks Certified Associate Developer for Apache Spark certification exam assesses the understanding of the Spark DataFrame API and the ability to apply it to basic data manipulation tasks. | [Learn more](https://www.databricks.com/learn/certification/apache-spark-developer-associate) |

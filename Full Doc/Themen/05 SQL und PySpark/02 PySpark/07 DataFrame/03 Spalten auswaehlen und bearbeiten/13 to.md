# `DataFrame.to()`

Gibt einen neuen DataFrame zurück, in dem jede Zeile an das angegebene Schema angeglichen wird.

## Signatur

```python
to(schema: StructType)
```

## Parameter

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| `schema` | `StructType` | Das Zielschema. |

## Rückgabewert

`DataFrame`: Angeglichener DataFrame.

## Hinweise

- Spalten und/oder innere Felder werden nach Namen umsortiert, um dem angegebenen Schema zu entsprechen.
- Spalten und/oder innere Felder, die im Zielschema nicht benötigt werden, werden wegprojiziert. Fehlende Spalten/Felder (im Zielschema vorhanden, aber nicht im Eingabe-DataFrame) führen zu Fehlern.
- Spalten und/oder innere Felder werden in die Datentypen des Zielschemas gecastet, sofern die Typen kompatibel sind – z. B. numerisch nach numerisch (Fehler bei Überlauf), aber nicht `string` nach `int`.
- Metadaten des Zielschemas werden übernommen; Spalten/Felder behalten ihre eigenen Metadaten, sofern das Zielschema sie nicht überschreibt.
- Schlägt fehl, wenn die Nullability nicht kompatibel ist, z. B. wenn eine Spalte nullable ist, das Zielschema aber NOT NULL verlangt.
- Unterstützt Spark Connect.

## Beispiel

```python
from pyspark.sql.types import StructField, StringType
df = spark.createDataFrame([("a", 1)], ["i", "j"])
df.schema
# StructType([StructField('i', StringType(), True), StructField('j', LongType(), True)])

schema = StructType([StructField("j", StringType()), StructField("i", StringType())])
df2 = df.to(schema)
df2.schema
# StructType([StructField('j', StringType(), True), StructField('i', StringType(), True)])
df2.show()
# +---+---+
# |  j|  i|
# +---+---+
# |  1|  a|
# +---+---+
```

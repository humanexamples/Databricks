# `DataFrame.na` (Eigenschaft)

Gibt ein `DataFrameNaFunctions`-Objekt zur Behandlung fehlender Werte zurück (`drop`, `fill`, `replace`).

## Rückgabewert

`DataFrameNaFunctions`

## Beispiele

```python
df = spark.sql("SELECT 1 AS c1, int(NULL) AS c2")
type(df.na)
# <class '...dataframe.DataFrameNaFunctions'>
```

Fehlende Werte durch 2 ersetzen:

```python
df.na.fill(2).show()
# +---+---+
# | c1| c2|
# +---+---+
# |  1|  2|
# +---+---+
```

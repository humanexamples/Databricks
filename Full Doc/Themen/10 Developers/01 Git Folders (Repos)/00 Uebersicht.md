# Git Folders (Repos) — Überblick

Databricks Git Folders (früher „Repos") integrieren Git-Repositories direkt in den Workspace. Diese Kapitel-Übersicht verweist auf die Detaildateien; verifiziert gegen die offizielle Databricks-Dokumentation (siehe Quellenangaben in den jeweiligen Dateien).

## Themen in diesem Kapitel

1. **Grundlagen** — Konzepte, Fähigkeiten, unterstützte Provider und Asset-Typen. Siehe [01 Grundlagen.md](01%20Grundlagen.md).
2. **Git-Integration konfigurieren** — Credentials (individuell/Gruppe), Commit-Identität, Netzwerk, Sicherheit, provider-spezifische Token-Erstellung. Siehe [02 Git-Integration konfigurieren.md](02%20Git-Integration%20konfigurieren.md).
3. **Git-Operationen** — Klonen, Branches, Commit/Push/Pull, Merge, Rebase, Reset, Sparse Checkout, Kollaboration. Siehe [03 Git-Operationen.md](03%20Git-Operationen.md).
4. **CI/CD und Automatisierung** — Produktions-Ordner-Muster, Service-Principal-Automatisierung, Terraform-Automatisierung. Siehe [04 CI-CD und Automatisierung.md](04%20CI-CD%20und%20Automatisierung.md).
5. **Administration und private Netzwerke** — API-Aktivierung, Git-Server-Proxy, Serverless Private Git. Siehe [05 Administration und private Netzwerke.md](05%20Administration%20und%20private%20Netzwerke.md).
6. **Fehlerbehebung** — häufige Fehler und Lösungen. Siehe [06 Fehlerbehebung.md](06%20Fehlerbehebung.md).

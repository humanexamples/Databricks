# 13 - Zusammenfassung und nächste Schritte

## Genie Code!

  ![](./Includes/images/common/genie-code.png)
**Probieren Sie Genie Code aus, um Ihre nächsten agentischen Spark Declarative Pipelines zu erstellen!**

Nachdem Sie nun die Grundlagen von Apache Spark™ Declarative Pipelines kennen – vom Definieren von Datasets und Verwalten von Abhängigkeiten bis zu Orchestrierung und Monitoring –, probieren Sie **Genie Code** aus, um Ihre Pipeline-Entwicklung zu beschleunigen.

Genie Code ist Ihr autonomer KI-Partner für die Arbeit mit Daten. Er ist in Notebooks, im SQL-Editor und in Dashboards integriert. Er kann Ihnen helfen, Pipeline-Definitionen zu schreiben, Code zu generieren, das Gerüst für Transformationslogik zu erstellen und Ihre Pipeline-Konfiguration schneller zu iterieren.

  [Introducing Genie Code →](https://www.databricks.com/blog/introducing-genie-code)

[AWS →](https://docs.databricks.com/aws/en/genie-code/)
[Azure →](https://learn.microsoft.com/en-us/azure/databricks/genie-code/)
[GCP →](https://docs.databricks.com/gcp/en/genie-code/)

- [Genie Code: Your autonomous AI partner for data engineering, science and analytics.](https://www.youtube.com/watch?v=UO0wvGYu5QQ)

- [Genie Code in action - An end-to-end demo.](https://youtu.be/heouBA5U1bE?si=0mObWn0Ex47FbVFd&t=275)
  - Beginnt bei *4:35* mit einem konkreten Beispiel für SDP.

Das ist nützlich, um:
- Spaltennamen zu bestätigen, bevor sie im Code referenziert werden
- Spalten zu identifizieren, die möglicherweise Umbenennung oder Typkonvertierung benötigen

df.columns

### C2. Spalten-Datentypen mit `df.dtypes` inspizieren

Das Attribut **`dtypes`** gibt den Datentyp jeder Spalte im DataFrame zurück. Datentypen zu verstehen ist essenziell, weil Operationen wie Arithmetik, Filterung und Datums-Parsing sich unterschiedlich verhalten, je nachdem, ob eine Spalte als String (`object`), Integer (`int64`), Float (`float64`) oder Datetime (`datetime64`) gespeichert ist.

Gängige pandas-Datentypen sind:

| dtype | Beschreibung |
|---|---|
| `object` | String- oder Mischtyp-Daten |
| `int64` | Ganze Zahlen |
| `float64` | Dezimalzahlen |
| `bool` | True/False-Werte |
| `datetime64[ns]` | Datums- und Zeitwerte |

```python
df.dtypes
```

```python
# Die Datentypen mehrerer Spalten abrufen.
df[["first_review", "last_review"]].dtypes
```

> **Hinweis:**

> Datumsspalten wie `first_review` und `last_review` werden oft standardmäßig als `object` (String) eingelesen. Wir konvertieren diese im nächsten Abschnitt.

## D. Mit Datumsspalten arbeiten

### D1. Datumsstrings mit `pd.to_datetime()` parsen

Wenn pandas eine CSV-Datei liest, werden Datumsspalten typischerweise als reine Strings (`object`-dtype) geladen. Um irgendwelche datumsbasierten Operationen durchzuführen – etwa das Sortieren nach Datum, das Berechnen von Zeitdifferenzen oder das Extrahieren von Jahr-/Monatswerten – muss die Spalte zuerst in einen echten `datetime64`-Typ konvertiert werden.

Die Funktion **`pd.to_datetime()`** parst eine `Series` von Datumsstrings in Datetime-Objekte. Wir verwenden den Parameter **`format`**, um pandas genau zu sagen, wie die Eingabestrings strukturiert sind.

```python
df["first_review"]
```

```python
df["last_review"]
```

Die Spalten `first_review` und `last_review` sind derzeit als reine Strings (object-dtype) gespeichert, nicht als Datetime-Objekte. Um mit diesen als Daten zu arbeiten, müssen wir sie mit `pd.to_datetime()` konvertieren. Standardmäßig leitet pandas das Datumsformat automatisch ab, sodass die Angabe eines Format-Strings optional ist, es sei denn, das Format ist mehrdeutig.

```python
# Das datetime-Objekt in ein datetime-Format umwandeln. 
df["first_review"] = pd.to_datetime(df["first_review"])
df["last_review"] = pd.to_datetime(df["last_review"])

df[["id", "first_review", "last_review"]].head(10)
```

```python
df[["first_review", "last_review"]].dtypes
```

### D2. Daten mit `strftime()` umformatieren

Sobald eine Spalte in `datetime64` konvertiert wurde, können wir die Datumswerte in jede benötigte String-Darstellung umformatieren, indem wir [**`strftime()`**](https://pandas.pydata.org/docs/reference/api/pandas.Series.dt.strftime.html) (kurz für „string format time") verwenden, das über den **`.dt`**-Accessor zugegriffen wird.

Wenn wir Daten im Format `MM-DD-YYYY` anzeigen möchten (z. B. `07-23-2009`), erreichen wir das mit dem Format-String **`"%m-%d-%Y"`**.

> **Hinweis:**
>
> `strftime()` konvertiert die Spalte zurück in den `object`-(String-)dtype. Wenn Sie die Spalte für weitere Datumsoperationen als `datetime64` behalten müssen, speichern Sie die formatierte Version in einer separaten Spalte.

```python
df["first_review_fmt"] = df["first_review"].dt.strftime("%m-%d-%Y")
df["last_review_fmt"] = df["last_review"].dt.strftime("%m-%d-%Y")

df[["id", "first_review", "first_review_fmt", "last_review", "last_review_fmt"]].head(10)
```

## E. Spalten umbenennen

### E1. `rename()` verwenden, um Spaltennamen zu aktualisieren

Wir können Spalten eines DataFrames mit [**`rename()`**](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.rename.html) umbenennen. Wir übergeben ein Dictionary an den Parameter **`columns`**, das alte Spaltennamen auf neue abbildet.

Die Syntax zum Umbenennen einer Spalte lautet:

```python
df = df.rename(columns={"old_name": "new_name"})
```

Die Syntax zum Umbenennen mehrerer Spalten lautet:

```python
df.rename(columns={"old_col_a": "new_col_a", "old_col_b": "new_col_b"})
```

Unten benennen wir die Spalte **`neighbourhood`** (britische Schreibweise) in **`neighborhood`** (amerikanische Schreibweise) um, um die Konsistenz zu verbessern.

```python
df = df.rename(columns={"neighbourhood": "neighborhood"})
df[["id", "neighborhood"]].head(10)
```

## F. Filtern

### F1. Boolean-Indexierung

Um eine Teilmenge von Zeilen auszuwählen, die eine bestimmte Bedingung erfüllen, verwenden Sie die Syntax **`df[bool_array]`**, wobei **`bool_array`** eine `Series` von `True`- und `False`-Werten ist – eine pro Zeile.

- Zeilen, die zu **`True`** ausgewertet werden, werden behalten.
- Zeilen, die zu **`False`** ausgewertet werden, werden entfernt.

Unten filtern wir nach allen Zeilen, in denen **`host_is_superhost`** gleich **`"t"`** ist, was bedeutet, dass der Airbnb-Eigentümer ein Superhost ist.

```python
filtered_df = df[df["host_is_superhost"] == "t"]
filtered_df[["id", "host_is_superhost"]].head(10)
```

Der Ausdruck `df["host_is_superhost"] == "t"` erzeugt das zugrunde liegende Boolean-Array. Inspizieren wir es direkt, um die `True`/`False`-Werte pro Zeile zu sehen.

```python
df["host_is_superhost"] == "t"
```

Wir können auch `!=` verwenden, um alle Datensätze zu finden, in denen der Host **kein** Superhost ist.

```python
df["host_is_superhost"] != "t"
```

### F2. Pandas-Boolean-Operatoren

Um mehrere Bedingungen auf einmal auszuwerten, verwenden Sie die **bitweisen Boolean-Operatoren** von pandas statt Pythons Standard-`and`/`or`/`not`:

| Python-Operator | Pandas-Äquivalent |
|---|---|
| `and` | `&` |
| `or` | `\|` |
| `not` | `~` |

Unten wählen wir alle Datensätze aus, in denen der Host ein Superhost ist **und** das Inserat mindestens 150 Bewertungen hat. Jede Bedingung muss in Klammern eingeschlossen werden.

```python
filtered_df = df[(df["host_is_superhost"] == "t") & (df["number_of_reviews"] >= 150)]
filtered_df[["id", "host_is_superhost", "number_of_reviews"]].head(10)
```

## G. Aggregatfunktionen

### G1. Grundlegende Aggregationen

Aggregatfunktionen nehmen eine Reihe von Eingaben und geben einen einzelnen Ausgabewert zurück. Gängige pandas-Aggregationen auf numerischen `Series` sind `mean()`, `min()` und `max()`.

Unten berechnen wir diese drei Statistiken auf der Spalte **`number_of_reviews`**.

```python
print(df["number_of_reviews"].mean())
print(df["number_of_reviews"].min())
print(df["number_of_reviews"].max())
```

### G2. Zusammenfassende Statistiken mit `describe()`

Die Methode [**`describe()`**](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.describe.html) generiert eine vollständige statistische Zusammenfassung einer numerischen `Series`, einschließlich Anzahl, Mittelwert, Standardabweichung, Min, Quartile und Max.

```python
df["number_of_reviews"].describe()
```

Wir können `describe()` auch auf einem DataFrame aufrufen, um es über mehrere numerische Spalten auf einmal anzuwenden.

```python
df[["number_of_reviews", "host_listings_count", "bedrooms"]].describe()
```

Um die Anzahl der Nachkommastellen in der Ausgabe zu reduzieren, verketten Sie [**`round()`**](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.round.html) an das Ergebnis und geben Sie die gewünschte Anzahl von Nachkommastellen an.

```python
df[["number_of_reviews", "host_listings_count", "bedrooms"]].describe().round(2)
```

## H. Group By

### H1. Gruppieren und aggregieren

Die Methode [**`groupby()`**](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.groupby.html) teilt den DataFrame basierend auf den Werten in einer oder mehreren Spalten in Gruppen auf und erlaubt es Ihnen, eine Aggregatfunktion unabhängig auf jede Gruppe anzuwenden.

Unten gruppieren wir nach **`neighborhood`** und berechnen die mittlere Anzahl von Schlafzimmern pro Nachbarschaft. Wir verwenden doppelte Klammern `[["bedrooms"]]`, sodass das Ergebnis als DataFrame statt als Series zurückgegeben wird, was es uns erlaubt, später bei Bedarf zusätzliche Spalten hinzuzufügen.

```python
df.groupby(["neighborhood"])
```

```python
grouped_df = df.groupby(["neighborhood"])[["bedrooms"]].mean().head(10)
grouped_df
```

### H2. Index zurücksetzen

DataFrames haben immer einen Index, der als die am weitesten links stehende Spalte angezeigt wird. Nach einer `groupby()`-Operation wird die Gruppierungsspalte (in diesem Fall **`neighborhood`**) zum Index statt zu einer regulären Spalte. Wir können das bestätigen, indem wir die Spalten inspizieren.

```python
grouped_df.columns
```

Verwenden Sie [**`reset_index()`**](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.reset_index.html), um den Standard-Integer-Index wiederherzustellen und die Gruppierungsspalte zurück zu einer regulären Spalte zu befördern. Das ist nützlich, wenn:

- Sie die gruppierte Spalte in nachgelagerte Berechnungen einbeziehen müssen
- Sie einen konsistenten, zusammenhängenden Integer-Index nach Umformungs-Operationen wünschen
- Sie Daten für den Export oder weitere Transformation vorbereiten

```python
reset_df = grouped_df.reset_index()
reset_df
```

## I. Sortieren

### I1. Einen DataFrame mit `sort_values()` sortieren

Pandas bietet [**`sort_values()`**](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.sort_values.html), um Zeilen in einem `DataFrame` oder einer `Series` zu sortieren.

Beim Sortieren eines `DataFrame` geben Sie die Spalte an, nach der sortiert werden soll. Standardmäßig erfolgt die Sortierung in **aufsteigender Reihenfolge**.

```python
sorted_df = df.sort_values(["bedrooms"])
sorted_df[["id","bedrooms"]].head(10)
```

Beim Sortieren einer `Series` gibt es nur eine Spalte, sodass kein Spaltenname benötigt wird.

```python
df["bedrooms"].sort_values()
```

### I2. Absteigende Reihenfolge

Übergeben Sie **`ascending=False`** an `sort_values()`, um die Sortierreihenfolge umzukehren.

```python
df["bedrooms"].sort_values(ascending=False)
```

## J. Fehlende Werte behandeln (NaN)

### J1. Fehlende Werte identifizieren

Fehlende Werte in pandas werden als **`NaN`** (Not a Number) dargestellt. Diese können Probleme in Berechnungen verursachen und müssen vor der Analyse behandelt werden.

Verwenden Sie [**`isna()`**](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.isna.html) (ein Alias für `isnull()`) kombiniert mit `sum()`, um die Anzahl der fehlenden Werte pro Spalte zu zählen.

```python
nan_df = df[["security_deposit", "notes"]] # Teilmenge der Spalten mit NaNs
nan_df
```

```python
nan_df.isna().sum()
```

### J2. NaN-Werte entfernen

Ein Ansatz zur Behandlung fehlender Werte ist, alle Zeilen zu entfernen, die sie enthalten, mit [**`dropna()`**](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.dropna.html).

> **Hinweis:**
>
> Dieser Ansatz verwirft Daten. Im Beispiel unten werden über 3.000 Zeilen entfernt, was möglicherweise nicht wünschenswert ist.

```python
nan_df.dropna()
```

### J3. Fehlende Werte mit `fillna()` imputieren

Statt Zeilen zu entfernen, können wir fehlende Werte **imputieren** – `NaN` durch einen sinnvollen Ersatz ersetzen – mit [**`fillna()`**](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.fillna.html).

Gängige Imputationsstrategien sind:

- **Numerische Spalten**: mit Mittelwert, Median oder null ersetzen
- **Kategoriale Spalten**: mit dem Modus oder einem speziellen Label wie `"Missing"` ersetzen

Übergeben Sie einen einzelnen Wert, um alle `NaN`-Werte einheitlich zu ersetzen, oder übergeben Sie ein **Dictionary**, um verschiedene Füllwerte pro Spalte anzuwenden.

```python
nan_df.fillna("Missing")
```

Unten geben wir an, dass **`security_deposit`** mit `"$0.00"` und **`notes`** mit `"Missing"` gefüllt werden soll. Das Setzen von **`inplace=False`** (der Standard) gibt einen neuen DataFrame zurück, ohne das Original zu ändern.

```python
nan_df.fillna({"security_deposit": "$0.00", "notes": "Missing"}, inplace=False)
```

load_df.head()

10. **Fehlende Werte behandeln**, indem Zeilen mit `dropna()` entfernt oder mit `fillna()` imputiert werden
11. **DataFrames persistieren** in CSV und sie mit `to_csv()` und `read_csv()` zurücklesen

# Demo – Kontrollfluss

## Überblick

Diese Demo führt den Python-Kontrollfluss ein – die Mechanismen, die bestimmen, welche Codezeilen ausgeführt werden und in welcher Reihenfolge. Standardmäßig wertet Python Code sequenziell von oben nach unten aus. Kontrollfluss-Werkzeuge wie `if`, `elif`, `else` und `pass` erlauben es Ihnen, bedingte Logik zu definieren, die die Ausführung basierend auf Boolean-Ausdrücken steuert. Sie erkunden außerdem Vergleichsoperatoren, die Boolean-Ergebnisse erzeugen, und üben, sie zu kombinieren, um ausdrucksstarke bedingte Programme zu erstellen. Außerdem verwenden Sie **Genie Code**, um Python-Kontrollfluss-Beispiele zu generieren, zu erklären und zu ändern, was Ihnen hilft, diese Konzepte interaktiv zu verstehen und anzuwenden.

2. **if-Anweisungen verwenden**, um Codeblöcke bedingt basierend auf Boolean-Ausdrücken auszuführen, einschließlich verschachtelter und verketteter `elif`-Strukturen

4. **Boolean-Operatoren** (`and`, `or`, `not`) und Vergleichsoperatoren (`<`, `>`, `<=`, `>=`, `==`, `!=`) anwenden, um ausdrucksstarke bedingte Ausdrücke zu erstellen

## A. Die if-Anweisung

### A1. Kontrollfluss und bedingte Logik

Python wertet standardmäßig jede Codezeile von oben nach unten sequenziell aus. Die Reihenfolge, in der Python Code ausführt, wird **Kontrollfluss** genannt. Python bietet Werkzeuge, um diesen Fluss basierend auf Bedingungen zu ändern.

Das erste Werkzeug ist die **if-Anweisung**. Sie wertet einen Boolean-Ausdruck aus und führt einen von zwei Codeblöcken aus, je nachdem, ob der Ausdruck **`True`** oder **`False`** ist.

Die Syntax lautet:

```
if bool:
    code_1
else:
    code_2
```

- `bool` ist ein Boolean-Ausdruck, der entweder zu **`True`** oder **`False`** ausgewertet wird
- Wenn **`True`**, führt Python `code_1` aus und überspringt `code_2`
- Wenn **`False`**, überspringt Python `code_1` und führt `code_2` aus

Die Zelle unten demonstriert eine einfache if-Anweisung mit einem fest codierten Boolean-Wert.

```python
if True:
    print("True")
else:
    print("False")
```

### A2. Ein praktisches if-Anweisungs-Beispiel

Die folgenden zwei Zellen demonstrieren eine praktischere Verwendung einer if-Anweisung. Ein Widget wird verwendet, um Benutzereingaben anzunehmen, und die Eingabe wird dann ausgewertet, um zu bestimmen, ob sie in einen gültigen Bereich fällt.

Führen Sie die erste Zelle aus, um das Widget zu erstellen, das oben auf der Seite erscheint. Geben Sie eine Zahl zwischen 1 und 10 ein und führen Sie dann die zweite Zelle aus, um sie auszuwerten.

```python
# A more practical example
# Eine Zahl eingeben (oben in der Anzeige)

dbutils.widgets.text("input", "1", "Enter a number from 1 - 10")  # Wir setzen 1 als Standardwert
input = dbutils.widgets.get("input")
```

```python
# Evaluate the input

input_as_number = int(input)
if input_as_number >= 1 and input_as_number <= 10:
    print("Valid Input")
else:
    print("Invalid Input")
    
# Remove the widget
dbutils.widgets.remove("input")
```

### A3. Einrückung

Beachten Sie die [Einrückung](https://www.w3schools.com/python/gloss_python_if_indentation.asp) in der if-Anweisung. Einrückung ist in Python nicht nur eine Stilpräferenz – **sie ist erforderlich, damit der Code korrekt läuft**.

Python verwendet die Einrückung, um zu bestimmen, welche Codezeilen innerhalb eines `if`- oder `else`-Blocks liegen. Code, der nicht korrekt eingerückt ist, löst entweder einen Fehler aus oder verhält sich unerwartet.

- Der Python-Standard ist **4 Leerzeichen** pro Einrückungsebene
- Die **`Tab`**-Taste ist ein bequemes Kürzel, das in den meisten Editoren die korrekten Abstände einfügt

## B. Vergleichsoperatoren

### B1. Boolean-Ausdrücke mit Vergleichsoperatoren

Da Sie nun if-Anweisungen schreiben können, ist der nächste Schritt, die darin verwendeten Boolean-Ausdrücke zu verstehen. Zusätzlich zu den logischen Operatoren `and`, `or` und `not` bietet Python **Vergleichsoperatoren**, die zwei Werte auswerten und ein Boolean-Ergebnis zurückgeben.

Die Tabelle unten fasst die verfügbaren Vergleichsoperatoren zusammen:

| Operator | Bedeutung | Beispiel |
|----------|-----------|----------|
| `<` | Kleiner als | `a < b -> bool` |
| `>` | Größer als | `a > b -> bool` |
| `<=` | Kleiner oder gleich | `a <= b -> bool` |
| `>=` | Größer oder gleich | `a >= b -> bool` |
| `==` | Gleich | `a == b -> bool` |
| `!=` | Ungleich | `a != b -> bool` |

**HINWEIS:** `=` wird für die Variablenzuweisung verwendet. `==` wird für den Gleichheitsvergleich verwendet.

Die Zelle unten demonstriert jeden Operator mit einer einfachen print-Anweisung.

```python
print(1 == 1)
print(1.5 != 2.5)
print("abc" == "xyz")
print(True == True)
```

### B2. Vergleichsoperatoren in if-Anweisungen verwenden

Das folgende Beispiel verwendet einen Vergleichsoperator innerhalb einer if-Anweisung, um zu entscheiden, ob das Mittagessen basierend auf seinem Preis gekauft wird. Ein Budget von 15 $ wird als Schwellenwert verwendet.

```python
lunch_price = 20

if lunch_price <= 15:
    print("Buy it!")
else:
    print("Too expensive")
```

### B3. Verschachtelte if-Anweisungen

Der Code innerhalb eines `if`- oder `else`-Blocks kann beliebiges gültiges Python sein – einschließlich einer weiteren if-Anweisung. Das nennt man **Verschachtelung** (nesting). Das Beispiel unten erweitert die Mittagessen-Entscheidung, indem eine zweite Bedingung innerhalb des `else`-Blocks hinzugefügt wird, um Preise zu behandeln, die hoch, aber nicht extrem sind.

```python
if lunch_price <= 15:
    print("Buy it!")
else:
    if lunch_price < 25:
        print("Is it really good?")
    else:
        print("This better be the best food of all time")
```

## C. Die elif-Anweisung

### C1. Bedingungen mit elif verketten

Verschachtelte if-Anweisungen funktionieren, aber Python bietet eine sauberere Alternative: die **`elif`**-Anweisung. `elif` erlaubt es Ihnen, mehrere Bedingungen in einer einzigen Kontrollfluss-Struktur zu verketten, ohne die Einrückung zu erhöhen.

Die Syntax lautet:

```
if bool:
    code_1
elif bool:
    code_2
elif bool:
    code_3
.
.
.
else:
    code_last
```

- Python wertet Bedingungen **von oben nach unten** aus
- Sobald eine Bedingung zu **`True`** ausgewertet wird, führt Python diesen Block aus und **überspringt alle verbleibenden** `elif`- und `else`-Klauseln
- Wenn keine Bedingung `True` ist, läuft der `else`-Block

Das Beispiel unten greift die Mittagessen-Entscheidung erneut auf und verwendet `elif`, um mehrere Preisbereiche sauber zu behandeln.

```python
lunch_price = 15

if lunch_price == 10:
    print("10 dollars exactly! Buy it!")
elif lunch_price <= 15:
    print("Buy it!")
elif lunch_price < 25:
    print("Is it really good?")
else:
    print("This better be the best food of all time")
```

## D. Die pass-Anweisung

### D1. pass als Platzhalter verwenden

Manchmal benötigen Sie beim Schreiben von Kontrollfluss-Strukturen einen Platzhalter für Code, den Sie später implementieren möchten. Die **`pass`**-Anweisung dient diesem Zweck – sie tut nichts, wenn sie ausgeführt wird, erlaubt es aber, dass der Code syntaktisch gültig bleibt.

Das ist nützlich, wenn Sie die Struktur eines Programms skizzieren, bevor Sie die Logik ausfüllen. Die Zelle unten zeigt `pass`, verwendet innerhalb sowohl eines `if`- als auch eines `else`-Blocks.

```python
if True:
    # Code, der später ergänzt wird, oder nichts tun 
    pass
else:
    # Code, der später ergänzt wird, oder nichts tun
    pass
```

Die `pass`-Anweisung stellt sicher, dass Ihr Code syntaktisch korrekt bleibt, während sie Raum für zukünftige Entwicklung lässt. Sie wird häufig verwendet, wenn bedingte Verzweigungen, Funktionskörper oder Schleifenstrukturen skizziert werden, bevor die vollständige Logik geschrieben ist.

## E. Bedingungen kombinieren: Hunderassen-Empfehlungen

### E1. Ein Multi-Bedingungs-Programm erstellen

Dieser Abschnitt bringt if-Anweisungen, elif, Vergleichsoperatoren und Boolean-Logik in einem realistischen Szenario zusammen. Das Programm empfiehlt eine Hunderasse basierend auf drei Eingaben:

- **`dog_person`** — Boolean: ob der Benutzer Hunde mag
- **`cat_person`** — Boolean: ob der Benutzer Katzen mag
- **`age`** — Integer: das Alter des Benutzers

Die Empfehlungslogik funktioniert wie folgt:

- Wenn der Benutzer **unter 18** ist, wird ihm gesagt, er solle seine Eltern um Erlaubnis fragen
- Andernfalls:
  - **Hunde- und Katzenmensch** → Golden Retriever (kommt gut mit Katzen aus)
  - **Nur Hundemensch** → Scottish Deerhound (dafür bekannt, Katzen zu jagen)
  - **Nur Katzenmensch** → ihm wird gesagt, er sei auf dem Holzweg
  - **Weder noch** → er wird gebeten zu bewerten, ob ein Haustier das Richtige für ihn ist

Die erste Implementierung verwendet eine **verschachtelte if-Anweisung** innerhalb des `else`-Blocks.

```python
dog_person = True
cat_person = True
age = 30

if age < 18:
    print("Ask your parents for permission!")
else:
    if dog_person and cat_person:
        print("Golden Retriever")
    else:
        if dog_person and not cat_person:
            print("Scottish Deerhound")
        else:
            if cat_person and not dog_person:
                print("You're barking up the wrong tree!")
            else:
                print("Are you sure a pet is right for you?")
```

### E2. Abflachen mit elif

Dieselbe Logik kann prägnanter geschrieben werden, indem die verschachtelte Struktur durch eine flache Kette von `elif`-Anweisungen ersetzt wird. Dieser Ansatz ist leichter zu lesen und vermeidet zusätzliche Einrückungsebenen.

> **Hinweis**
>
> Die Reihenfolge der Bedingungen ist wichtig. Python stoppt bei der ersten `True`-Bedingung, also müssen spezifischere Bedingungen (wie `age < 18`) vor breiteren stehen.

```python
dog_person = True
cat_person = True
age = 30

if age < 18:
    print("Ask your parents for permission!")
elif dog_person and cat_person:
    print("Golden Retriever")
elif dog_person and not cat_person:
    print("Scottish Deerhound")
elif cat_person and not dog_person:
    print("You're barking up the wrong tree!")
else:
    print("Are you sure a pet is right for you?")
```

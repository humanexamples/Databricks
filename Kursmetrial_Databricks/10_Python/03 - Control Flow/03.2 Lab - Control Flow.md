## Aufgabe 1: Einen Essens-Empfehler bauen

### Aufgabe 1.1. Eingaben und Empfehlungslogik definieren

Schreiben Sie die Kontrollfluss-Logik für einen einfachen Essens-Empfehler. Benutzer liefern die folgenden Eingaben:

- **`temperature`**: Ein Float, der die Außentemperatur darstellt (in Fahrenheit)
- **`sunny`**: Ein Boolean, gesetzt auf **`True`**, wenn es draußen sonnig ist, sonst **`False`**

Schreiben Sie Logik, die die folgenden Empfehlungen ausgibt:

| Bedingung | Empfehlung |
| --- | --- |
| Temperatur ≥ 60 °F **und** sonnig | `ice cream` |
| Temperatur ≥ 60 °F **und** nicht sonnig | `dumplings` |
| Temperatur < 60 °F (jedes Wetter) | `hot tea` |

```python
temperature = <FILL_IN>
sunny = <FILL_IN>

if <FILL_IN>:
    print(<FILL_IN>)
elif <FILL_IN>:
    print(<FILL_IN>)
else:
    print(<FILL_IN>)
```

### Aufgabe 1.1 — Eingaben und Empfehlungslogik definieren — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
temperature = 72.0
sunny = False

if temperature >= 60.0 and sunny:
    print("ice cream")
elif temperature >= 60.0 and not sunny:
    print("dumplings")
else:
    print("hot tea")
```

</details>

## Aufgabe 2: Einen Auto-Wartungsberater bauen

### Aufgabe 2.1. Eingaben und Wartungslogik definieren

Schreiben Sie die Kontrollfluss-Logik für einen Auto-Wartungsberater. Benutzer liefern die folgenden Eingaben:

- **`km_since_last_change`**: Ein Integer, der die Anzahl der Kilometer seit dem letzten Ölwechsel darstellt
- **`oil_change_light`**: Ein Boolean, gesetzt auf **`True`**, wenn die Ölwechsel-Leuchte an ist, sonst **`False`**

Schreiben Sie Logik, die die folgenden Empfehlungen ausgibt:

| Bedingung | Empfehlung |
| --- | --- |
| km ≥ 15.000 **und** Leuchte ist an | `Time for an oil change` |
| km ≥ 15.000 **und** Leuchte ist aus | `Wait for the light` |
| km < 15.000 (unabhängig von der Leuchte) | `Wait longer` |

```python
km_since_last_change = <FILL_IN>
oil_change_light = <FILL_IN>

if <FILL_IN>:
    print(<FILL_IN>)
elif <FILL_IN>:
    print(<FILL_IN>)
else:
    print(<FILL_IN>)
```

### Aufgabe 2.1 — Eingaben und Wartungslogik definieren — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
km_since_last_change = 15000
oil_change_light = True

if km_since_last_change >= 15000 and oil_change_light:
    print("Time for an oil change")
elif km_since_last_change >= 15000 and not oil_change_light:
    print("Wait for the light")
else:
    print("Wait longer")
```

</details>

## Aufgabe 3: Einen Schaltjahr-Rechner erstellen

### Aufgabe 3.1. Die Schaltjahr-Regeln verstehen

Ein Jahr gilt als Schaltjahr, wenn es die folgenden Kriterien erfüllt:

- Ist ohne Rest durch **4** teilbar UND eines der folgenden ist wahr:
  - Ist ohne Rest durch **400** teilbar (z. B. war 2000 ein Schaltjahr), ODER
  - Ist **nicht** ohne Rest durch **100** teilbar (z. B. wird 2100 kein Schaltjahr sein)

Sie können die Teilbarkeit mit dem **Modulo-Operator** (`%`) prüfen:

| Ausdruck | Ergebnis |
| --- | --- |
| `2000 % 4 == 0` | `True` |
| `1901 % 4 == 0` | `False` |

> **Tipp: Verschachtelte Logik**
>
> Die verschachtelte Einrückung in den obigen Regeln legt nahe, dass verschachtelte `if`-Anweisungen die natürlichste Art sein könnten, diese Logik zu implementieren. Erwägen Sie, die Teilbarkeit durch 4 in einem äußeren Block zu prüfen und dann die 400/100-Regeln in einem inneren Block zu behandeln.

### Aufgabe 3.2. Den Modulo-Operator verstehen

Bevor Sie Funktionen schreiben, die Teilbarkeit testen, hilft es, den **Modulo-Operator (`%`)** zu verstehen.

Modulo gibt den **Rest** der Division einer ganzen Zahl durch eine andere zurück. Das ist besonders nützlich, um zu bestimmen, ob eine Zahl ohne Rest teilbar ist – wenn der Rest `0` ist, ist die Division exakt.

**Beispiele:**
- `12 % 7` → `5` (12 geteilt durch 7 ist 1, mit Rest 5)
- `10 % 2` → `0` (10 ist ohne Rest durch 2 teilbar, also ist es gerade)
- `7 % 2` → `1` (7 ist nicht ohne Rest durch 2 teilbar, also ist es ungerade)

Führen Sie die Zelle unten aus, um zu bestätigen, wie sich Modulo verhält.

```python
12 % 7
```

Implementieren Sie mithilfe des Widget-Werts die oben beschriebene Schaltjahr-Logik.

- Benennen Sie die Eingabevariable **`year`** (casten Sie den Widget-Wert zu einem Integer)

### Aufgabe 3.4. — Schaltjahr-Logik implementieren — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

    print(f"{year} is not a leap year.")

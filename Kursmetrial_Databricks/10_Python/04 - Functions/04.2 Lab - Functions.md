### Aufgabe 1.1: Die Funktion `even_or_odd()` definieren

Schreiben Sie mithilfe des Modulo-Operators eine Funktion namens **`even_or_odd(num)`**, die:

- Einen einzelnen Integer-Parameter `num` akzeptiert
- Den String `"even"` zurückgibt, wenn `num` durch 2 teilbar ist
- Andernfalls den String `"odd"` zurückgibt

**HINWEIS:** Verwenden Sie `return` statt `print()` im Funktionskörper, damit die Test-Assertions unten das Ergebnis auswerten können.


##### Aufgabe 1.1 — Die Funktion `even_or_odd()` definieren — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

## Aufgabe 2: Eine Fizz-Buzz-Funktion definieren

### Aufgabe 2.1: Die Funktion `fizz_buzz()` definieren

Fizz Buzz ist eine klassische Programmierübung, die Ihre Fähigkeit testet, mehrere bedingte Prüfungen zu kombinieren. Schreiben Sie eine Funktion namens **`fizz_buzz(num)`**, die die folgenden Regeln der Reihe nach anwendet:

1. Wenn die Eingabe **kein Integer** ist, gib `"Wrong type"` zurück
2. Wenn der Integer durch **sowohl 3 als auch 5** teilbar ist, gib `"FizzBuzz"` zurück
3. Wenn der Integer **nur durch 5** teilbar ist, gib `"Fizz"` zurück
4. Wenn der Integer **nur durch 3** teilbar ist, gib `"Buzz"` zurück
5. Wenn der Integer durch **keines** teilbar ist, gib die Zahl selbst zurück

> **Tipp: Ordnen Sie Ihre Bedingungen sorgfältig**
>
> Prüfen Sie den Typ der Eingabe, *bevor* Sie die Teilbarkeit prüfen. Prüfen Sie dann auf Teilbarkeit durch sowohl 3 als auch 5, bevor Sie jede einzeln prüfen – andernfalls wird der kombinierte Fall nie erreicht. Verwenden Sie `elif`, um Ihre Bedingungen zu verketten.

```python
## def fizz_buzz(num):
    # <FILL-IN>
```

##### Aufgabe 2.1 — Die Funktion `fizz_buzz()` definieren — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
def fizz_buzz(num):
    if type(num) != int:
        return "Wrong type"
    elif num % 5 == 0 and num % 3 == 0:
        return "FizzBuzz"
    elif num % 5 == 0:
        return "Fizz"
    elif num % 3 == 0:
        return "Buzz"
    else:
        return num
```

</details>

## Aufgabe 3: Eine Schaltjahr-Funktion definieren

### Aufgabe 3.1: Die Funktion `is_leap_year()` definieren

Ein **Schaltjahr** tritt auf, wenn ein Jahr die folgenden Bedingungen erfüllt:

- Es ist **ohne Rest durch 4 teilbar** UND eines der folgenden ist wahr:
  - Es ist **ohne Rest durch 400 teilbar** (z. B. war 2000 ein Schaltjahr), ODER
  - Es ist **nicht ohne Rest durch 100 teilbar** (z. B. wird 2100 kein Schaltjahr sein)

Schreiben Sie eine Funktion namens **`is_leap_year(year)`**, die:

- Einen einzelnen Integer-Parameter `year` akzeptiert
- Verschachtelte `if`/`else`-Anweisungen verwendet, um zu bestimmen, ob das Jahr ein Schaltjahr ist
- `"{year} is a leap year."` ausgibt, wenn `year` ein Schaltjahr ist
- Andernfalls `"{year} is not a leap year."` ausgibt

> **Tipp: Verwenden Sie verschachtelte Bedingungen**
>
> Die Struktur der Schaltjahr-Regeln bildet sich natürlich auf verschachtelte `if`-Anweisungen ab. Beginnen Sie mit der Prüfung der Teilbarkeit durch 4 und verschachteln Sie darin eine zweite Prüfung für die 400/100-Bedingung.

```python
## def is_leap_year(year):
    # <FILL-IN>
```

##### Aufgabe 3.1 — Die Funktion `is_leap_year()` definieren — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
def is_leap_year(year):
    if year % 4 == 0:
        if year % 400 == 0 or year % 100 != 0:
            print(f"{year} is a leap year.")
        else:
            print(f"{year} is not a leap year.")
    else:
        print(f"{year} is not a leap year.")
```

</details>

# Demo – Funktionen

## Überblick

Funktionen sind einer der grundlegendsten Bausteine der Python-Programmierung. Indem Sie wiederverwendbare Logik in einen benannten Codeblock einwickeln, können Sie Wiederholung vermeiden, die Lesbarkeit verbessern und modulare Programme erstellen, die leichter zu warten sind.

In dieser Demo erkunden Sie, wie man Python-Funktionen definiert und aufruft, wie man Daten mit Parametern und Argumenten an sie übergibt, wie man Werte zurückgibt und wie man seine Funktionen mit Type Hints, Code-Kommentaren und Docstrings dokumentiert. Sie lernen außerdem den Variablen-Scope kennen, Pythons eingebaute Funktionen und wie man anonyme Funktionen mit Lambda-Ausdrücken erstellt.

## Lernziele

Am Ende dieser Demonstration können Sie:

1. **Python-Funktionen definieren und aufrufen** mit dem Schlüsselwort `def`, mit und ohne Parameter
2. **Argumente übergeben** an Funktionen über positionelle, benannte und gemischte Aufrufstile
3. **Standard-Parameterwerte und das Schlüsselwort `return` verwenden**, um wiederverwendbare, kombinierbare Funktionen zu erstellen
4. **Type Hints, Code-Kommentare und Docstrings anwenden**, um Lesbarkeit und Dokumentation von Funktionen zu verbessern
5. **Den Variablen-Scope erklären** und wie er die Zugänglichkeit von Variablen innerhalb und außerhalb von Funktionen beeinflusst
6. **Pythons eingebaute Funktionen verwenden** und ihre Dokumentation mit `help()` aufrufen
7. **Lambda-(anonyme)-Funktionen erstellen und verwenden** für prägnante, einzeilige Operationen
8. **Wichtige Erkenntnisse zusammenfassen** über Funktionen und ihre Rolle beim Schreiben von sauberem, modularem Python-Code

## A. Einführung in Funktionen

### A1. Was ist eine Funktion?

Eine [Funktion](https://www.w3schools.com/python/python_functions.asp) ist ein benannter, wiederverwendbarer Codeblock, der eine bestimmte Aufgabe ausführt. Statt dieselbe Logik wiederholt zu schreiben, definieren Sie sie einmal und rufen sie auf, wann immer Sie sie brauchen.

Die Syntax zum Definieren einer Funktion in Python lautet:

```
def function_name(parameters):
    function_code
```

- Das Schlüsselwort **`def`** signalisiert den Beginn einer Funktionsdefinition.
- Der **Funktionsname** folgt auf `def` und sollte beschreiben, was die Funktion tut.
- **Parameter** (optional) erscheinen innerhalb der Klammern.
- Ein **Doppelpunkt** beendet die Signaturzeile, und der Funktionskörper wird darunter eingerückt.

Sie haben bereits Funktionen verwendet: **`print()`** ist eine eingebaute Python-Funktion.

```python
print(1)
```

### A2. Eine einfache Funktion definieren

Schreiben wir eine Funktion ohne Parameter. Sie wandelt einen festen Betrag von 10 US-Dollar in Euro um, mit einem Umrechnungskurs von **0,93** (der ungefähre Kurs zum Zeitpunkt, als diese Lektion geschrieben wurde).

Die Einrückung des Codes im Funktionskörper ist erforderlich – genau wie bei `if`-Anweisungen verwendet Python die Einrückung, um zu bestimmen, welche Zeilen innerhalb der Funktion liegen. Verwenden Sie **`Tab`**, um die Einrückung zu erstellen.

```python
def ten_dollars_to_euros():
    print(10.0 * 0.93)
```

Das Definieren der Funktion führt sie nicht aus – es passiert nichts, bis wir die Funktion aufrufen. Das allgemeine Muster zum Aufrufen einer Funktion lautet:

```
function_name(arguments)
```

```python
ten_dollars_to_euros()
```

Wenn Python auf einen Funktionsaufruf trifft, springt es in den Funktionskörper, führt den dortigen Code aus und kehrt dann zur Zeile unmittelbar nach dem Aufruf zurück.

Das Beispiel unten zeigt, dass Python Code der Reihe nach ausführt – der Funktionskörper läuft nur, wenn die Funktion aufgerufen wird.

```python
print("Python ran this line before the function body")

ten_dollars_to_euros()

print("Python ran this line after the function body")
```

## B. Parameter und Argumente

### B1. Parameter

Eine feste Funktion wie `ten_dollars_to_euros()` ist eingeschränkt – sie wandelt immer genau 10 Dollar um. Um unsere Funktion flexibler zu machen, damit sie mit verschiedenen Dollar-Beträgen funktioniert, können wir einen **Parameter** verwenden.

**Parameter** machen Funktionen flexibel, indem sie als Platzhalter für Werte fungieren, die beim Aufruf der Funktion geliefert werden.

Durch Hinzufügen eines `dollar_amount`-Parameters können wir mit derselben Funktion jeden Dollar-Wert in Euro umwandeln.

```python
def dollars_to_euros(dollar_amount):
    print(dollar_amount * 0.93)
```

### B2. Argumente

Wenn Sie eine Funktion mit Parametern aufrufen, müssen Sie für jeden Parameter einen Wert liefern. Der Wert, den Sie übergeben, wird [**Argument**](https://www.w3schools.com/python/gloss_python_function_arguments.asp) genannt.

Im Aufruf `dollars_to_euros(5)` wird der Wert `5` dem Parameter `dollar_amount` zugewiesen, und der Funktionskörper läuft mit diesem Wert.

```python
dollars_to_euros(5.0)
dollars_to_euros(10)
dollars_to_euros(20.0)
```

### B3. Mehrere Parameter

Funktionen können mehr als einen Parameter akzeptieren, indem sie durch Kommas getrennt werden. Das Beispiel unten fügt einen `conversion_rate`-Parameter hinzu, sodass der Kurs aktualisiert werden kann, ohne die Funktionsdefinition zu ändern.

```python
def dollars_to_euros_with_rate(dollar_amount, conversion_rate):
    print(dollar_amount * conversion_rate)
```

Wenn Sie eine Funktion mit mehreren Parametern aufrufen, geben Sie für jeden einen Wert an, durch Kommas getrennt. Wenn Sie ein Argument weglassen, löst Python einen `TypeError` aus.

```python
dollars_to_euros_with_rate(10.0, 0.93)
dollars_to_euros_with_rate(5.0, 1.0)
# dollars_to_euros_with_rate(5.0) # Wenn diese Zeile einkommentiert wird, tritt ein TypeError auf
```

Das obige Muster verwendet **positionelle Argumente** – das erste Argument wird dem ersten Parameter zugewiesen, das zweite dem zweiten und so weiter.

### B4. Benannter und gemischter Aufruf

#### B4.1 Benannter Aufruf

Sie können Argumente auch übergeben, indem Sie den Parameter, dem sie entsprechen, explizit benennen. Wenn Sie das tun, spielt die Reihenfolge der Argumente keine Rolle mehr.

```python
dollars_to_euros_with_rate(dollar_amount=10.0, conversion_rate=0.93)
dollars_to_euros_with_rate(conversion_rate=0.93, dollar_amount=10.0)
```

#### B4.2 Gemischter Aufruf

Positionelle und benannte Argumente können in einem einzigen Aufruf kombiniert werden, aber **positionelle Argumente müssen immer zuerst kommen**. Sobald Sie beginnen, Argumente zu benennen, kann Python sich nicht mehr auf die Position verlassen, um Werte zuzuweisen.

Im Beispiel unten erhält `dollar_amount` `10.0` per Position, und `conversion_rate` wird per Name angegeben. Die auskommentierte Zeile würde fehlschlagen, weil `dollar_amount` zweimal zugewiesen würde.

```python
dollars_to_euros_with_rate(10.0, conversion_rate=0.93)
# dollars_to_euros_with_rate(10.0, dollar_amount=0.93) # Das würde einen TypeError auslösen
```

## C. Standard-Parameterwerte und return

### C1. Standard-Parameterwerte

[Standardwerte](https://www.w3schools.com/python/gloss_python_function_default_parameter.asp) erlauben es, dass ein Parameter optional ist. Wenn der Aufrufer keinen Wert für diesen Parameter liefert, wird automatisch der Standardwert verwendet.

Die Syntax für einen Standardwert lautet:

```
def func(param, param=default_value):
    code
```

**HINWEIS:** Parameter mit Standardwerten müssen immer **nach** Parametern ohne Standardwerte aufgeführt werden.

Im Beispiel unten ist `conversion_rate` standardmäßig `0.93`, wenn nicht angegeben.

```python
def dollar_to_euro_with_default(dollar_amount, conversion_rate=0.93):
    print(dollar_amount * conversion_rate)
```

Der erste Aufruf verwendet den Standardkurs; der zweite überschreibt ihn mit `0.5`.

```python
dollar_to_euro_with_default(10.0)
dollar_to_euro_with_default(10.0, 0.5)
```

### C2. Funktionsausgabe mit `return`

Bisher geben unsere Funktionen nur Werte aus. Wenn Sie versuchen, das Ergebnis einer solchen Funktion einer Variablen zuzuweisen, werden Sie feststellen, dass es zu **`None`** ausgewertet wird – einem speziellen Python-Typ, der das Fehlen eines Werts darstellt.

```python
a = dollar_to_euro_with_default(10.0)
print(a)
```

Die Funktion gibt während der Ausführung `9.3` aus, aber die Variable `a` hält `None`, weil die Funktion keinen Wert produziert, den Python in einem Ausdruck verwenden kann.

Um eine Funktion ein nutzbares Ergebnis produzieren zu lassen, verwenden Sie das Schlüsselwort [**`return`**](https://www.w3schools.com/python/ref_keyword_return.asp). Wenn Python `return` erreicht, verlässt es die Funktion sofort und gibt den angegebenen Wert an den Aufrufer zurück.

```python
def dollar_to_euro_with_default(dollar_amount, conversion_rate=0.93):
    return dollar_amount * conversion_rate
```

```python
a = dollar_to_euro_with_default(10.0)
print(a)
```

Jetzt wird `dollar_to_euro_with_default(10.0)` zu `9.3` ausgewertet, genau wie es der Ausdruck `10.0 * 0.93` direkt tut. Der zurückgegebene Wert kann in einer Variablen gespeichert, an eine andere Funktion übergeben oder in jedem Ausdruck verwendet werden.

## D. Type Hints und Dokumentation

### D1. Type Hints

Python ist eine dynamisch typisierte Sprache, was bedeutet, dass Sie jeden Typ als Argument übergeben können – selbst wenn die Funktion nur für die Arbeit mit einem bestimmten Typ ausgelegt ist. [Type Hints](https://docs.python.org/3/library/typing.html) lassen Sie die erwarteten Typen von Parametern und Rückgabewerten annotieren, was die Lesbarkeit verbessert und statischen Analysewerkzeugen ermöglicht, Fehler früh zu erkennen.

Die Syntax lautet:
- **Parameter-Hint:** `param_name: type`
- **Rückgabe-Hint:** `-> return_type:` am Ende der Signaturzeile

Das Beispiel unten annotiert sowohl die Parameter als auch den Rückgabewert als `float`.

```python
def dollar_to_euro_with_default(dollar_amount: float, conversion_rate: float = 0.93) -> float:
    return dollar_amount * conversion_rate
```

> **Type Hints werden nicht erzwungen**
>
> Python erzwingt Type Hints zur Laufzeit nicht. Sie können weiterhin den falschen Typ übergeben, und die Funktion wird versuchen zu laufen. Ihr Hauptnutzen ist verbesserte Lesbarkeit und Kompatibilität mit Werkzeugen wie **mypy** und IDE-Autovervollständigung.

### D2. Code-Kommentare

[**Code-Kommentare**](https://www.w3schools.com/python/python_comments.asp) sind Klartext-Annotationen, die direkt in Ihren Code mit dem Symbol `#` geschrieben werden. Code-Kommentare werden nicht als Teil des Funktionsobjekts gespeichert – sie dienen ausschließlich dazu, die Logik jedem zu erklären, der den Quellcode liest.

Kommentare sind besonders nützlich, um:

- Zu verdeutlichen, **warum** ein bestimmter Wert oder Ansatz gewählt wurde
- Zu beschreiben, was eine bestimmte Zeile oder ein Codeblock tut
- Notizen für Mitwirkende oder Ihr zukünftiges Ich zu hinterlassen

Ein Kommentar kann auf einer eigenen Zeile über dem Code stehen, den er beschreibt, oder inline am Ende einer Anweisung. Python ignoriert alles auf einer Zeile nach dem Symbol `#`, sodass Kommentare keine Auswirkung auf die Ausführung haben.

Im Beispiel unten erklärt ein Kommentar über dem Funktionsaufruf den Zweck jedes übergebenen Arguments.

```python
# 10 Dollar mit dem Standard-Umrechnungskurs von 0,93 in Euro umrechnen
dollar_to_euro_with_default(dollar_amount=10.0, conversion_rate=0.93)
```

### D3. Docstrings

[**Docstrings**](https://peps.python.org/pep-0257/) sind strukturierte String-Literale, die am Anfang eines Funktionskörpers platziert werden, um zu beschreiben, was die Funktion tut, welche Parameter sie erwartet und was sie zurückgibt. Sie werden in dreifache Anführungszeichen (`"""`) eingeschlossen.

Anders als reguläre Kommentare werden Docstrings als Eigenschaft des Funktionsobjekts gespeichert und können programmatisch abgerufen werden.

```python
def dollar_to_euro_with_default(dollar_amount: float, conversion_rate: float = 0.93) -> float:
    """
    Returns Dollar amount converted to Euros based on a conversion rate.
    
    Parameters:
        dollar_amount (float): Dollar amount to be converted to euros.
        conversion_rate (float): Dollar to Euro conversion rate. Default: 0.93.
    
    Returns:
        euro_amount (float): Euro equivalent of the dollar amount based on the conversion rate.
    """
    euro_amount = dollar_amount * conversion_rate
    return euro_amount
```

Die eingebaute Funktion **`help()`** liest den Docstring einer Funktion und zeigt ihn in einer formatierten Ausgabe an. Das ist besonders nützlich beim Arbeiten mit unbekannten Funktionen.

```python
help(dollar_to_euro_with_default)
```

> **Genie Code verwenden, um Code-Kommentare und Docstrings zu erstellen**
>
> Sie können Genie Code verwenden, um Ihnen beim Erstellen von Code-Kommentaren und Docstrings zu helfen. Und Sie können einen Code-Kommentar in eine Zelle schreiben, und Genie Code liefert Ihnen Code-Vorschläge.

## E. Scope und eingebaute Funktionen

### E1. Variablen-Scope

[Scope](https://www.w3schools.com/python/python_scope.asp) bezieht sich auf den Codebereich, in dem eine Variable zugänglich ist. In Python sind Variablen, die innerhalb einer Funktion definiert werden, **lokal** zu dieser Funktion – sie existieren nur, während die Funktion läuft, und können nicht von außen zugegriffen werden.

Das ist wichtig zu verstehen beim Debuggen: Wenn Sie eine Variable innerhalb einer Funktion definieren und versuchen, sie außerhalb zu verwenden, löst Python einen `NameError` aus.

```python
def function():
    func_variable = 1
    return func_variable
```

```python
function()
# func_variable  # Wenn diese Zeile einkommentiert wird, tritt ein NameError auf – func_variable ist außerhalb des Gültigkeitsbereichs
```

### E2. Pythons eingebaute Funktionen

Python wird mit einer Bibliothek von [eingebauten Funktionen](https://docs.python.org/3/library/functions.html) geliefert, die gängige Operationen abdecken. Sie haben bereits `print()` verwendet. Zwei weitere häufig verwendete eingebaute Funktionen sind:

| Funktion | Beschreibung | Beispiel |
|---|---|---|
| `print()` | Zeigt einen Wert auf der Konsole an | `print("hello")` |
| `max()` | Gibt den größten der Eingabewerte zurück | `max(1, 2)` → `2` |
| `len()` | Gibt die Anzahl der Elemente in einer Sequenz zurück | `len("abc")` → `3` |

```python
# max() gibt den größeren von zwei Werten zurück: 2 > 1
print(max(1, 2))

# len() gibt die Anzahl der Zeichen in einem String zurück: "abc" hat 3
print(len("abc"))
```

Sie können `help()` auf jeder eingebauten Funktion aufrufen, um ihre Dokumentation zu lesen, genau wie Sie es mit der benutzerdefinierten Funktion oben getan haben.

```python
help(max)
```

## F. Lambda-Funktionen

### F1. Was ist eine Lambda-Funktion?

Eine [**Lambda-Funktion**](https://www.w3schools.com/python/python_lambda.asp) ist eine anonyme Funktion mit einem einzigen Ausdruck, die mit dem Schlüsselwort `lambda` statt `def` definiert wird. Da sie keinen Namen und keine `return`-Anweisung hat, eignet sie sich am besten für kurze Einweg-Operationen – besonders wenn eine Funktion als Argument an eine andere Funktion übergeben wird.

Die Syntax lautet:

`lambda` *`parameters`*: *`expression`*

- **`lambda`** ersetzt `def function_name`.
- **`parameters`** funktionieren wie in einer regulären Funktion.
- Der **Ausdruck** wird automatisch ausgewertet und zurückgegeben – kein `return`-Schlüsselwort wird benötigt.

Die Tabelle unten vergleicht die zwei Stile nebeneinander:

| Merkmal | `def`-Funktion | `lambda`-Funktion |
|---|---|---|
| Hat einen Namen | Ja | Nein (anonym) |
| Unterstützt mehrere Anweisungen | Ja | Nein – nur ein einziger Ausdruck |
| Unterstützt Docstrings | Ja | Nein |
| Kann einer Variablen zugewiesen werden | Ja | Ja |
| Häufiger Anwendungsfall | Wiederverwendbare, dokumentierte Logik | Kurze Inline-Callbacks |

```python
# Ein einfaches Lambda, das 10 zu einer Zahl addiert
# Dabei ist a: der Parameter und a + 10 der Ausdruck bzw. Rückgabewert
add_ten = lambda a: a + 10

print(add_ten(5))   # 15
print(add_ten(22))  # 32
```

### F2. Ein Lambda definieren und aufrufen

Ein Lambda kann einer Variablen zugewiesen und wie eine reguläre Funktion aufgerufen werden. Das Beispiel unten schreibt den Währungsumrechner als Lambda um.

> **Hinweis:**
>
> Ein Lambda einer Variablen zuzuweisen ist zum Lernen nützlich, aber in Produktionscode wird eine benannte `def`-Funktion bevorzugt, weil sie Docstrings unterstützt und leichter zu debuggen ist.

```python
# Lambda-Funktion zur Umrechnung von Dollar in Euro mit einem Standard-Umrechnungskurs von 0,93
dollars_to_euros_lambda = lambda dollar_amount, conversion_rate=0.93: dollar_amount * conversion_rate

print(dollars_to_euros_lambda(10.0))        # Uses default rate: 9.3
print(dollars_to_euros_lambda(10.0, 0.5))   # Overrides rate: 5.0
```

### F3. Lambdas als Inline-Argumente

Die häufigste Verwendung von Lambda-Funktionen ist, sie direkt als Argumente an Funktionen höherer Ordnung zu übergeben – Funktionen, die eine andere Funktion als Parameter akzeptieren. Pythons eingebaute `sorted()` und `max()` akzeptieren beide einen `key`-Parameter, der eine Funktion erwartet.

Das Beispiel unten sortiert eine Liste von Währungsumrechnungs-Dictionaries nach ihrem `rate`-Wert, indem ein Lambda als `key`-Argument verwendet wird. Ohne das Lambda wüsste `sorted()` nicht, nach welchem Feld sortiert werden soll.

```python
rates = [
    {"currency": "GBP", "rate": 0.79},
    {"currency": "JPY", "rate": 149.50},
    {"currency": "EUR", "rate": 0.93},
]

# Die Liste mithilfe eines Lambdas als Schlüsselfunktion nach dem Wert 'rate' sortieren
sorted_rates = sorted(rates, key=lambda r: r["rate"])

for entry in sorted_rates:
    print(entry)
```

> **Wann lambda vs. def verwenden**
>
> Verwenden Sie ein **lambda**, wenn die Logik kurz ist, nur einmal verwendet wird und direkt als Argument übergeben wird. Verwenden Sie **def**, wenn die Funktion einen Docstring braucht, sich über mehrere Zeilen erstreckt oder in Ihrem Code wiederverwendet wird.

## G. Fazit

In dieser Demo haben Sie die Kernkonzepte von Python-Funktionen erkundet:

1. **Funktionen** werden mit `def` definiert und per Name aufgerufen, was es Ihnen erlaubt, Logik wiederzuverwenden, ohne Code zu wiederholen.
2. **Parameter und Argumente** lassen Sie Daten in Funktionen übergeben; Argumente können positionell, benannt oder gemischt sein.
3. **Standard-Parameterwerte** machen Argumente optional, indem sie einen Ausweichwert in der Funktionssignatur bereitstellen.
4. **Das Schlüsselwort `return`** produziert aus einer Funktion einen Wert, der in Ausdrücken verwendet oder einer Variablen zugewiesen werden kann.
5. **Type Hints** annotieren erwartete Parameter- und Rückgabetypen, um die Lesbarkeit zu verbessern; sie werden zur Laufzeit nicht erzwungen.
6. **Code-Kommentare** verwenden das Symbol `#`, um Logik inline zu annotieren, und helfen Lesern, die Absicht hinter dem Code zu verstehen.
7. **Docstrings** dokumentieren den Zweck, die Parameter und den Rückgabewert einer Funktion und sind über `help()` zugänglich.
8. **Scope** begrenzt die Zugänglichkeit von Variablen – Variablen, die innerhalb einer Funktion definiert werden, sind außerhalb nicht verfügbar.
9. **Eingebaute Funktionen** wie `print()`, `max()` und `len()` sind vordefinierte Hilfsprogramme, die in jeder Python-Umgebung verfügbar sind.
10. **Lambda-Funktionen** bieten eine prägnante, anonyme Alternative zu `def` für Logik mit einem einzigen Ausdruck und werden häufig als Inline-`key`-Argumente für eingebaute Funktionen wie `sorted()` und `max()` verwendet.

## Aufgabe 1: Einen DataFrame erstellen

### Aufgabe 1.1: pandas importieren

Bevor Sie mit pandas arbeiten, importieren Sie die Bibliothek mit dem konventionellen Alias `pd`. Dieser Alias wird im gesamten pandas-Ökosystem verwendet und macht Ihren Code prägnanter.

```python
import pandas as pd
```

### Aufgabe 1.2: Den DataFrame bauen

Ein pandas-`DataFrame` ist eine zweidimensionale, tabellarische Datenstruktur mit beschrifteten Zeilen und Spalten – ähnlich einer Tabellenkalkulation oder SQL-Tabelle. Sie können einen erstellen, indem Sie eine Liste von Zeilen und eine Liste von Spaltennamen an `pd.DataFrame()` übergeben.

Erstellen Sie einen `DataFrame` namens `df`, der die folgende Tabelle von Hunden repräsentiert:

| Name | Age | Breed |
|--------|-----|---------------------|
| Buddy | 3 | Australian Shepherd |
| Harley | 10 | Labrador |
| Luna | 2 | Golden Retriever |
| Bailey | 8 | Chihuahua |

```python
## data = [["Buddy", 3, "Australian Shepherd"], ["Harley", 10, "Labrador"], ["Luna", 2, "Golden Retriever"], ["Bailey", 8, "Chihuahua"]]

## column_names = # <FILL-IN>

## df = # <FILL-IN>
## df
```

##### Aufgabe 1.2 — Den DataFrame bauen — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
data = [["Buddy", 3, "Australian Shepherd"], ["Harley", 10, "Labrador"], ["Luna", 2, "Golden Retriever"], ["Bailey", 8, "Chihuahua"]]
column_names = ["Name", "Age", "Breed"]

df = pd.DataFrame(data=data, columns=column_names)
df
```

</details>

## Aufgabe 2: Spalten-Datentypen inspizieren

### Aufgabe 2.1: Auf das `dtypes`-Attribut zugreifen

Jeder pandas-`DataFrame` stellt ein `dtypes`-Attribut bereit, das den Datentyp jeder Spalte zurückgibt. Das ist nützlich, um zu bestätigen, dass numerische Spalten als Integer oder Float gespeichert sind und dass Textspalten als `object` gespeichert sind (die pandas-Darstellung von Strings).

Geben Sie das `dtypes`-Attribut von `df` aus, um den jeder Spalte zugewiesenen Typ zu inspizieren.

> **Hinweis:**
>
> Attribute werden mit der Punktnotation zugegriffen – `object.attribute` – ohne Klammern.

```python
## df.TODO
```

##### Aufgabe 2.1 — Auf das `dtypes`-Attribut zugreifen — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
df.dtypes
```

</details>

## Aufgabe 3: Eine Teilmenge von Spalten auswählen

### Aufgabe 3.1: Auf bestimmte Spalten filtern

Sie können mehrere Spalten aus einem `DataFrame` auswählen, indem Sie eine Liste von Spaltennamen in doppelten Klammern übergeben: `df[["col1", "col2"]]`. Das gibt einen neuen `DataFrame` zurück, der nur die angegebenen Spalten enthält.

Wählen Sie nur die Spalten `Name` und `Age` aus `df` aus und weisen Sie das Ergebnis einer neuen Variablen namens `name_age_df` zu.

```python
## name_age_df = TODO
## name_age_df
```

##### Aufgabe 3.1 — Auf bestimmte Spalten filtern — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
name_age_df = df[["Name", "Age"]]
name_age_df
```

</details>

## Aufgabe 4: Eine neue Spalte ableiten

### Aufgabe 4.1: Menschliches Alter berechnen

Sie können einem `DataFrame` eine neue Spalte hinzufügen, indem Sie einem neuen Spaltennamen einen berechneten Ausdruck zuweisen: `df["New Column"] = df["Existing Column"] * value`. Diese Operation wird elementweise über jede Zeile angewendet.

Angenommen, ein Hundejahr entspricht 7 Menschenjahren, erstellen Sie eine neue Spalte namens `Human Age` in `df`, indem Sie die Spalte `Age` mit 7 multiplizieren.

```python
## df["Human Age"] = <FILL-IN>
```

##### Aufgabe 4.1 — Menschliches Alter berechnen — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
df["Human Age"] = df["Age"] * 7
df
```

</details>

## Aufgabe 5: Einen bestimmten Wert extrahieren

### Aufgabe 5.1: Filtern und extrahieren

Um einen einzelnen Wert aus einem `DataFrame` zu extrahieren, können Sie Boolean-Filterung mit Spaltenauswahl verketten. Das Muster `df[df["Column"] == value]["OtherColumn"][0]` filtert zunächst Zeilen, in denen die Bedingung wahr ist, wählt die Zielspalte aus und ruft dann das erste Element nach Indexposition ab.

Extrahieren Sie programmatisch Buddys `Breed` aus `df` und weisen Sie es der Variablen `breed` zu.

```python
## breed = TODO
## breed
```

##### Aufgabe 5.1 — Filtern und extrahieren — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
breed = df[df["Name"] == "Buddy"]["Breed"][0]
breed
```

</details>

# Demo – Pandas-Überblick

## Überblick

[Pandas](https://pandas.pydata.org/pandas-docs/stable/reference/index.html) ist eine grundlegende Python-Bibliothek für die Datenanalyse und bietet flexible und effiziente Datenstrukturen für die Arbeit mit tabellarischen Daten. In dieser Demo lernen Sie, wie man `DataFrame`- und `Series`-Objekte erstellt und bearbeitet, ihre Datentypen versteht und gängige Operationen zur Datenexploration und -transformation durchführt.

3. **`Series`-Objekte auswählen und damit arbeiten** über Klammer-Indexierung und Attribut-Referenz
4. **Spalten-Datentypen (`dtypes`) inspizieren und interpretieren** und ihre Auswirkung auf Operationen verstehen
5. **Elementweise Operationen durchführen und Spalten auswählen** aus einem `DataFrame`

## A. Einführung in `pandas`

### A1. Warum `pandas`?

Daten stehen branchenübergreifend zunehmend im Zentrum von Entscheidungen. Werkzeuge wie Excel sind zwar für einfache Analysen nützlich, stoßen aber an ihre Grenzen, wenn Sie Workflows automatisieren, an einer gemeinsamen Codebasis zusammenarbeiten oder auf größere Datensätze skalieren müssen.

`pandas` adressiert diese Einschränkungen, indem es eine leistungsstarke, programmierbare Schnittstelle für die Datenanalyse in Python bietet:

- Analysen automatisieren, sodass sie jeden Tag auf neuen Daten erneut laufen
- Eine teilbare, versionskontrollierte Codebasis mit Kollegen aufbauen
- Robuste Analysen durchführen, die direkt in Geschäftsentscheidungen einfließen
- Daten für Machine-Learning-Pipelines aufbereiten und transformieren

`pandas` ist eine der Kernbibliotheken, die von Datenanalysten und Data Scientists in Python verwendet werden. Es ist auf Databricks vorinstalliert.

Die Zelle unten importiert `pandas` mit dem Alias `pd`, was die Standardkonvention ist und es Ihnen erlaubt, die Bibliothek zu referenzieren, ohne jedes Mal `pandas` vollständig auszuschreiben.

```python
import pandas as pd
```

## B. Der Datentyp `DataFrame`

### B1. Einen `DataFrame` erstellen

`pandas` ist eine Bibliothek, die Datentypen und Funktionen für rigorose, programmatische Datenanalyse bereitstellt. Der zentrale `pandas`-Datentyp ist der [`DataFrame`](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.html).

Ein `DataFrame` ist eine zweidimensionale Tabelle aus benannten Zeilen und Spalten, ähnlich einer SQL-Tabelle. Die `DataFrame`-Klasse akzeptiert ein `data`-Attribut, das den Inhalt der Tabelle bei der Instanziierung definiert.

Um einen `DataFrame` zu erstellen, können Sie eine Liste von Listen übergeben, bei der jede innere Liste eine Datenzeile repräsentiert. Betrachten Sie die folgende Tabelle:

| Name | Age | Job |
|------|-----|------------|
| John | 30 | Journalist |
| Mary | 30 | Programmer |
| Abe | 40 | Chef |

Die Zelle unten konstruiert diese Tabelle als `DataFrame`. Da `DataFrame` innerhalb von `pandas` definiert ist, wird es mit `pd.DataFrame()` instanziiert.

```python
data = [["John", 30, "Journalist"], ["Mary", 30, "Programmer"], ["Abe", 40, "Chef"]]

df = pd.DataFrame(data=data)
df
```

### B2. Spaltennamen hinzufügen

Die oben gezeigten Spaltenüberschriften `0`, `1`, `2` sind Standard-Integer-Werte, die zugewiesen werden, wenn keine Spaltennamen angegeben sind. Um aussagekräftige Spaltennamen zuzuweisen, übergeben Sie eine Liste von Strings an das `columns`-Attribut von `pd.DataFrame()`.

```python
cols = ["Name", "Age", "Job"]
df = pd.DataFrame(data=data, columns=cols)
df
```

### B3. Einen DataFrame aus einem NumPy-`ndarray` erstellen

Sie können einen DataFrame auch aus einem NumPy-Array erstellen. Das ist nützlich, wenn Ihre Daten bereits in Array-Form vorliegen, etwa nach numerischen Berechnungen oder nach dem Laden aus externen Quellen. Übergeben Sie einfach das NumPy-Array als `data`-Argument und geben Sie Spaltennamen mit dem `columns`-Parameter an.

```python
import numpy as np

np_array = np.array([
    ["John", 30, "Journalist"],
    ["Mary", 30, "Programmer"],
    ["Abe", 40, "Chef"]
])

df2 = pd.DataFrame(data=np_array, columns=cols)
df2
```

```python
df2.dtypes
```

> **Hinweis:**
>
> Beim Erstellen eines DataFrames aus einem NumPy-Array, das gemischte Typen enthält, weist NumPy allen Elementen den dtype „object" zu, sodass pandas alle Spalten als object-dtype ableitet.

## C. Der Datentyp `Series`

### C1. Eine `Series` aus einem `DataFrame` auswählen

Der andere primäre Datentyp in `pandas` ist die [`Series`](https://pandas.pydata.org/docs/reference/api/pandas.Series.html). Eine `Series` repräsentiert eine einzelne Spalte eines `DataFrame`.

Es gibt zwei Möglichkeiten, eine `Series` aus einem `DataFrame` auszuwählen:

1. `df["column_name"]` — Klammer-Indexierung (bevorzugt)
2. `df.column_name` — Attribut-Referenz

Beide Ansätze werden unten mit der Spalte `Age` demonstriert. Es wird bevorzugt, `df["column_name"]` zu verwenden, weil die Attribut-Referenz-Notation nicht funktioniert, wenn Spaltennamen Leerzeichen enthalten.

```python
df["Age"]
```

```python
df.Age
```

```python
df2["Age"]
```

> **Hinweis:**
>
> Die Spalte „Age" in df2 ist nicht int64, weil das NumPy-Array gemischte Typen (Strings und Integer) enthält, sodass pandas alle Spalten als object-dtype ableitet.

## D. `dtypes` und `Series`-Operationen

### D1. `dtypes` verstehen

Wenn Sie eine `Series` anzeigen, bemerken Sie ein `dtype`-Label am unteren Rand (z. B. `dtype: int64`). In `pandas` beschreibt [`dtypes`](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.dtypes.html) – kurz für Datentypen – den Typ der in einer Spalte gespeicherten Werte.

Genau wie Pythons eingebaute Typen bestimmen, welche Operationen gültig sind, bestimmt der `dtype` einer `pandas`-Spalte, welche Operationen darauf durchgeführt werden können. Zum Beispiel können Sie den Durchschnitt einer numerischen Spalte berechnen, aber nicht einer Textspalte.

Die häufigsten `pandas`-dtypes und ihre Python-Äquivalente sind:

| `pandas`-dtype | Beschreibung | Python-Äquivalent |
|----------------|--------------------------|-------------------|
| `object` | Text-/String-Daten | `str` |
| `int64` | Integer-Werte | `int` |
| `float64` | Gleitkomma-Werte | `float` |
| `bool` | Boolean-Werte | `bool` |

Sie können den `dtype` jeder Spalte in einem `DataFrame` anzeigen, indem Sie auf sein `dtypes`-Attribut zugreifen.

```python
df.dtypes
```

### D2. Operationen auf einer `Series` durchführen

Operationen auf einer `Series` verhalten sich ähnlich wie Operationen auf ihren Python-Gegenstücktypen, aber sie wirken **elementweise** – das heißt, die Operation wird auf jeden Wert in der Spalte angewendet.

Zum Beispiel erzeugt das Addieren zweier `int64`-`Series` eine neue `Series`, bei der jedes Element die Summe der entsprechenden Elemente ist.

```python
df["Age"] + df["Age"]
```

Alle grundlegenden arithmetischen Operationen werden auf numerischen `Series` unterstützt. Der Ausdruck unten multipliziert jeden `Age`-Wert mit `3` und subtrahiert `1`.

```python
df["Age"] * 3 - 1
```

### D3. Einen einzelnen Wert aus einer `Series` auswählen

Um einen einzelnen Wert aus einer `Series` abzurufen, verwenden Sie eine integer-basierte Index-Notation – dieselbe Syntax, die zum Indexieren in eine Python-Liste verwendet wird. Das Beispiel unten ruft den ersten Wert aus der Spalte `Age` ab (Indexposition `0`).

```python
df["Age"][0]
```

## E. Teilmengen eines `DataFrame` auswählen

### E1. Mehrere Spalten auswählen

Zusätzlich zur Auswahl einer einzelnen Spalte als `Series` können Sie eine Teilmenge von Spalten auswählen und das Ergebnis als `DataFrame` zurückgeben. Übergeben Sie eine Liste von Spaltennamen innerhalb der äußeren Klammern mit der folgenden Syntax:

```python
df[[col_1, col_2, col_3, ...]]
```

Die Zelle unten wählt nur die Spalten `Name` und `Age` aus dem `DataFrame` aus.

```python
df[["Name", "Age"]]
```

```python
df[["Name", "Job"]]
```

### E2. `.iloc` für integer-basierte Indexierung verwenden

Die Methode `.iloc` erlaubt es Ihnen, Zeilen und Spalten anhand ihrer Integer-Positionen auszuwählen.

Die Syntax lautet:

```python
df.iloc[row_selection, column_selection]
```

Im Ausdruck `df.iloc[:, [0, 2]]` bedeutet der Doppelpunkt (`:`) vor dem Komma „alle Zeilen auswählen", während `[0, 2]` nach dem Komma die erste und dritte Spalte angibt. Das ist nützlich, wenn Sie Spalten nach ihrer Reihenfolge statt nach ihrem Namen auswählen möchten.

```python
# Get the original dataframe
df
```

```python
# Nur die erste und dritte Spalte abrufen
df.iloc[:, [0, 2]]
```

```python
# Die erste Zeile als DataFrame abrufen.
df.iloc[:1, :]
```

```python
# Die erste Zeile als Series abrufen. 
df.iloc[0, :]
```

> **Hinweis:**
>
> Beispiele, wie man `iloc` verwendet, um bestimmte Zeilen und Spalten anhand ihrer Integer-Positionen auszuwählen:
> - `iloc[0, 0]` holt die erste Zelle – 'John'
> - `iloc[:, 0]` holt die gesamte erste Spalte
> - `iloc[0, :]` holt die gesamte erste Zeile

## F. Veränderlichkeit von `DataFrame`-Objekten

### F1. Standardmäßig unveränderliches Verhalten

Wenn Sie eine Operation durchführen, die einen `DataFrame` ändert – etwa das Entfernen einer Spalte –, gibt `pandas` standardmäßig ein **neues Objekt** zurück und lässt den ursprünglichen `DataFrame` unverändert. Dieses Verhalten macht es sicherer, komplexe Datenpipelines aufzubauen, da Zwischen-Transformationen die Quelldaten nicht unbeabsichtigt überschreiben.

Die Zelle unten entfernt die Spalte `Age` und zeigt das Ergebnis an. Da das Ergebnis keiner Variablen zugewiesen wird, wird es nach der Anzeige verworfen.

```python
df.drop("Age", axis=1)
```

Der ursprüngliche `DataFrame` `df` ist unverändert, wie durch erneutes Anzeigen bestätigt wird. Um das Ergebnis einer Operation wie `drop()` zu behalten, weisen Sie das zurückgegebene Objekt einer neuen Variablen zu.

```python
df
```

Wenn Sie einen DataFrame ohne eine bestimmte Spalte wünschen, müssen Sie das Ergebnis einer neuen Variablen zuweisen. Zum Beispiel erstellt `new_df = df.drop("column_name", axis=1)` einen neuen DataFrame ohne die bestimmte Spalte und lässt den ursprünglichen `df` unverändert.

```python
df_no_age = df.drop("Age", axis=1)
df_no_age
```

> **Hinweis:**
>
> Der `axis`-Parameter gibt an, ob die Operation auf Spalten oder Zeilen angewendet wird.
> - `axis=1` bedeutet, auf Spalten operieren (z. B. eine Spalte entfernen).
> - `axis=0` bedeutet, auf Zeilen operieren (z. B. eine Zeile entfernen).

### F2. In-Place-Änderung mit `inplace=True`

Wenn Sie einen `DataFrame` direkt ändern möchten – ohne ein neues Objekt zu erstellen –, können Sie `inplace=True` an die Operation übergeben. In diesem Fall wird kein neues Objekt zurückgegeben; die Änderung wird auf den ursprünglichen `DataFrame` angewendet.

Die Zelle unten entfernt die Spalte `Age` an Ort und Stelle.

```python
df.drop("Age", axis=1, inplace=True)
```

Die Spalte `Age` wurde dauerhaft aus `df` entfernt, wie unten gezeigt.

```python
df
```

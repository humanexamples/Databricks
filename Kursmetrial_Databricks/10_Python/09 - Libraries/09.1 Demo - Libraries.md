# Demo – Bibliotheken

## Überblick

Diese Demo führt grundlegende Konzepte zum Organisieren und Erweitern von Python-Code in Databricks ein: den Magic-Befehl **`%run`** und Python-Bibliotheken. Sie sehen, wie `%run` es einem Notebook erlaubt, auf den Zustand – Funktionen, Klassen und Variablen – zuzugreifen, der in einem anderen Notebook definiert ist. Sie erkunden außerdem, wie Python-Bibliotheken von PyPI Pythons eingebaute Fähigkeiten erweitern, wie man sie mit `%pip` installiert und wie man sie in Ihrem Code importiert und verwendet. Die Demo behandelt auch das Erkunden von Bibliotheksdokumentation mit `help()`.

## Lernziele

Am Ende dieser Demonstration können Sie:

1. **Den Magic-Befehl `%run` verwenden**, um ein separates Notebook auszuführen und auf seine definierten Funktionen und Variablen zuzugreifen.
2. **Erklären, was PyPI ist**, und seine Rolle im Python-Ökosystem beschreiben.
3. **Eine Python-Bibliothek installieren** in Databricks mit `%pip install`.
4. **Eine Bibliothek importieren** mit `import`, `import` mit Alias und `from ... import`-Syntax.
5. **Die Funktion `help()` verwenden**, um die Dokumentation einer Bibliothek und ihrer Elemente zu erkunden.
6. **Databricks-spezifisches Bibliotheksmanagement und Interpreter-Verhalten verstehen.**

## A. Notebooks mit `%run` ausführen

### A1. Wie `%run` funktioniert

Der Magic-Befehl **`%run`** erlaubt es einem Notebook, alle Befehlszellen eines *anderen* Notebooks auszuführen. Nachdem das referenzierte Notebook gelaufen ist, wird sein gesamter Zustand – alle Klassen, Funktionen und Variablen, die es definiert – im aufrufenden Notebook verfügbar.

Wichtige Regeln für die Verwendung von `%run`:

- Der Befehl `%run` muss am **Anfang** einer Befehlszelle stehen.
- Kein Python-Code darf vor oder nach `%run` in derselben Zelle stehen.
- Der Pfad nach `%run` verweist auf das Ziel-Notebook (relativ oder absolut).

Die Zelle unten führt das Notebook `run_example` aus, das sich im Verzeichnis `../Includes/` befindet.

```text
%run ../Includes/run_example
```

## B. Auf den Zustand des referenzierten Notebooks zugreifen

Das Notebook `run_example` definiert eine Funktion namens **`greet()`**, die einen Namen akzeptiert und einen Begrüßungs-String zurückgibt. Da `%run` den vollständigen Zustand dieses Notebooks importiert, ist `greet()` nun hier verfügbar – obwohl es nie in diesem Notebook definiert wurde.

Dieses Muster ist nützlich, um Hilfsfunktionen in einem dedizierten Notebook zu definieren und zu testen, wodurch Ihr Haupt-Notebook sauber und fokussiert bleibt.

```python
greet("Bob")
```

## C. PyPI und das Importieren von Python-Bibliotheken

### C1. Was ist PyPI?

Wenn Python installiert wird, enthält es einen Standardsatz von Hilfsprogrammen namens [Python Standard Library](https://docs.python.org/3/library/). Darüber hinaus können Entwickler ihre eigenen Bibliotheken für die Python-Community über **PyPI** – den [Python Package Index](https://pypi.org/) – veröffentlichen.

PyPI ist das zentrale Repository, in das Entwickler Bibliotheken hochladen und teilen und aus dem Benutzer sie herunterladen. Es enthält Tausende von Paketen, die ein breites Spektrum von Anwendungsfällen abdecken – viele davon sind zu Industriestandards geworden.

Standardmäßig hat Python keinen Zugriff auf PyPI-Bibliotheken. Bevor Sie eine verwenden können, muss sie auf Ihrem System installiert sein.

### C2. Eine Bibliothek importieren

Sobald eine Bibliothek installiert ist, müssen Sie sie **importieren**, bevor Sie sie verwenden können. Die einfachste Form ist:

```python
import numpy
```

> **numpy ist vorinstalliert**
>
> Die Databricks Runtime enthält **numpy** und mehrere andere beliebte Bibliotheken standardmäßig – keine manuelle Installation erforderlich. Eine vollständige Liste finden Sie in den [Databricks Runtime Release Notes](https://docs.databricks.com/en/release-notes/runtime/index.html).

## D. Bibliotheken installieren und verwenden

### D1. Bibliotheken mit `%pip` installieren

**`pip`** ist das Standardwerkzeug zum Herunterladen und Installieren von Paketen von PyPI. In einem Terminal würden Sie `pip install package_name` ausführen. In Databricks verwenden Sie stattdessen den Magic-Befehl **`%pip`** innerhalb einer Notebook-Zelle.

Zum Beispiel, um `numpy` zu installieren:

```
%pip install numpy
```

Die Zelle unten demonstriert den Befehl `%pip --help`, um verfügbare pip-Optionen anzuzeigen.

**HINWEIS:** Das Ausführen von `%pip install` startet den Python-Interpreter neu. Platzieren Sie `%pip`-Befehle am **Anfang** Ihres Notebooks, um zu vermeiden, dass die Ergebnisse zuvor ausgeführter Zellen verloren gehen.

```text
%pip --help
```

Die Zelle unten installiert `numpy`. Beachten Sie, dass dies den Python-Interpreter neu startet – Sie müssen das Notebook `./Includes/run_example` danach erneut ausführen, um den Zugriff auf `greet()` wiederherzustellen.

```text
%pip install numpy
```

### D2. Eine Bibliothek verwenden

Nachdem eine Bibliothek installiert ist, müssen Sie sie **importieren**, bevor Sie sie verwenden können. Sie können auf Funktionen mit der Punktnotation zugreifen:

`numpy.function_name(arguments)`

Das Beispiel unten importiert `numpy` und verwendet seine Funktion `sqrt()`, um die Quadratwurzel einer Zahl zu berechnen – eine Fähigkeit, die nicht in Python selbst eingebaut ist.

```python
import numpy

numpy.sqrt(4.0)
```

### D3. Einen Alias verwenden

Sie können einer Bibliothek beim Import mit dem Schlüsselwort **`as`** einen kürzeren Alias zuweisen. Das reduziert den Tippaufwand beim wiederholten Aufrufen von Bibliotheksfunktionen. Der Alias `np` ist die Community-Konvention für `numpy`.

```python
import numpy as np

np.sqrt(4.0)
```

### D4. Bestimmte Funktionen importieren

Sie können eine einzelne Funktion direkt aus einer Bibliothek mit der **`from ... import`**-Syntax importieren. Das bringt die Funktion in den lokalen Namensraum, sodass Sie sie ohne das Bibliothekspräfix aufrufen können.

```python
from numpy import sqrt

sqrt(4.0)
```

## E. Grundlegende NumPy-Nutzung

Da `numpy` nun installiert und importiert ist, erkunden wir einige seiner Kernfunktionen. NumPy ist die grundlegende Bibliothek für numerisches Rechnen in Python und bietet effiziente Array-Operationen und mathematische Funktionen.

### E1. Arrays mit `ndarray` erstellen

Das zentrale Objekt in NumPy ist das **`ndarray`** (n-dimensionales Array). Sie können Arrays aus Python-Listen mit `np.array()` erstellen oder sie mit Hilfsfunktionen wie `np.zeros()`, `np.ones()` und `np.arange()` generieren.

```python
import numpy as np

# Ein Array aus einer Python-Liste erstellen
a = np.array([1, 2, 3, 4, 5])
print("From list:", a)

# Create a 2D array
b = np.array([[1, 2, 3], [4, 5, 6]])
print("2D array:\n", b)

# Useful creation functions
print("Zeros:", np.zeros(4))
print("Ones:", np.ones(3))
print("Range:", np.arange(0, 10, 2))
```

### E2. Datentypen (`dtype`)

Jedes NumPy-Array hat einen **`dtype`**, der den Typ seiner Elemente beschreibt (z. B. `int64`, `float64`, `bool`). Sie können ihn mit dem Attribut `.dtype` inspizieren und bei der Erstellung angeben.

```python
# Der Standard-dtype wird aus den Daten abgeleitet
int_array = np.array([1, 2, 3])
print("Integer array dtype:", int_array.dtype)

float_array = np.array([1.0, 2.0, 3.0])
print("Float array dtype:", float_array.dtype)

# Specify dtype explicitly
specified = np.array([1, 2, 3], dtype=np.float32)
print("Specified dtype:", specified.dtype, "| Values:", specified)
```

### E3. Indexierung, Slicing und Striding

NumPy-Arrays unterstützen dieselbe Indexierungs- und Slicing-Syntax wie Python-Listen, erweitert auf mehrere Dimensionen. Sie können auch einen **Stride** (Schrittweite) verwenden, um Elemente zu überspringen.

```python
arr = np.array([10, 20, 30, 40, 50, 60, 70, 80])

# Basic indexing
print("First element:", arr[0])
print("Last element:", arr[-1])

# Slicing [start:stop]
print("Elements 1-3:", arr[1:4])

# Striding [start:stop:step]
print("Every other element:", arr[::2])
print("Reversed:", arr[::-1])
```

### E4. Aggregationen

NumPy bietet effiziente Aggregationsfunktionen, die auf ganzen Arrays oder entlang einer bestimmten Achse operieren. Gängige Aggregationen sind `sum()`, `mean()`, `min()`, `max()` und Standardabweichung: `std()`.

```python
grades = np.array([75, 80, 85, 90, 95, 78, 82, 88, 91])

print("Sum of all elements:", grades.sum())
print("Mean of all elements:", grades.mean())
print("Max value:", grades.max())
print("Min value:", grades.min())
print("Standard deviation:", grades.std())
```

## F. Bibliotheksdokumentation mit `help()` erkunden

### F1. `help()` auf einer Bibliothek und ihren Elementen verwenden

Die eingebaute Funktion **`help()`** zeigt die Dokumentation für jedes Python-Objekt an – einschließlich ganzer Bibliotheken und einzelner Funktionen darin. Das ist nützlich, um zu entdecken, was eine Bibliothek bietet, und zu verstehen, wie man ihre Funktionen verwendet, ohne das Notebook zu verlassen.

- Übergeben Sie eine Bibliothek an `help()`, um ihre vollständige Dokumentation zu sehen.
- Übergeben Sie eine bestimmte Funktion an `help()`, um ihre Signatur, Parameter und Beschreibung zu sehen.

```python
help(np)
```

```python
help(np.sqrt)
```

## G. Fazit

In dieser Demo haben Sie wesentliche Mechanismen zum Erweitern und Organisieren von Python-Code in Databricks erkundet:

1. **PyPI** ist das zentrale Repository für Python-Bibliotheken, und **`%pip install`** wird in Databricks verwendet, um Pakete daraus zu installieren.
2. **`import`**, **`import ... as`** und **`from ... import`** sind drei Möglichkeiten, Bibliotheksfunktionalität in Ihr Notebook zu bringen.
3. NumPy bietet leistungsstarke Funktionen zur Array-Erstellung, Datentypen, Indexierung, Slicing, Striding und Aggregation für numerisches Rechnen.
4. Die Funktion **`help()`** bietet Inline-Dokumentation für Bibliotheken und ihre Elemente.

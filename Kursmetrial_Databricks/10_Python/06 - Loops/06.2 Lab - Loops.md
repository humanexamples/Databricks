## Aufgabe 1: Mit For-Schleifen arbeiten

### Aufgabe 1.1: Die Funktion `detention_helper()` erstellen

Bart Simpson hat wieder Nachsitzen. Er muss **`I will not let my dog eat my homework`** 50-mal schreiben. Da Bart nach einem effizienteren Ansatz sucht, helfen Sie ihm, das in Python mit einer `for`-Schleife zu automatisieren.

Schreiben Sie eine Funktion namens **`detention_helper()`**, die zwei Parameter akzeptiert:

* **`detention_message`** — die Nachricht, die Bart schreiben muss
* **`num_lines`** — die Anzahl der Male, die er sie schreiben muss

Die Funktion sollte **`detention_message`** genau **`num_lines`**-mal ausgeben, wobei jede Zeile beginnend bei `1` nummeriert ist.

**Beispielausgabe** (für `detention_message = "I will not let my dog eat my homework"` und `num_lines = 50`):

```
1. I will not let my dog eat my homework
2. I will not let my dog eat my homework
3. I will not let my dog eat my homework
...
50. I will not let my dog eat my homework
```

> **Tipp: `range()` verwenden**
>
> Verwenden Sie die Funktion `range()`, aber stellen Sie sicher, dass Sie bei `1` zu zählen beginnen, nicht bei `0`. F-String-Formatierung ist hier ebenfalls hilfreich.

```python
## def detention_helper(detention_message, num_lines):
##     <FILL_IN>
```

##### Aufgabe 1.1 — Die Funktion `detention_helper()` erstellen — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
def detention_helper(detention_message, num_lines):
    for i in range(num_lines):
        print(f"{i+1}. {detention_message}")
```

</details>

### Aufgabe 1.2: Die Funktion aufrufen

Rufen Sie Ihre Funktion `detention_helper()` mit den korrekten Eingaben für Barts aktuelles Nachsitzen auf. Überprüfen Sie, dass `"I will not let my dog eat my homework"` 50-mal ausgegeben wird, wobei jede Zeile wie im Beispiel oben nummeriert ist.

```python
## detention_helper(<FILL_IN>, <FILL_IN>)
```

##### Aufgabe 1.2 — Die Funktion aufrufen — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
detention_helper("I will not let my dog eat my homework", 50)
```

</details>

## Aufgabe 2: Mit While-Schleifen arbeiten

### Aufgabe 2.1: `detention_helper()` mit einer While-Schleife neu schreiben

Schreiben Sie die Funktion `detention_helper()` aus **1.1** neu, indem Sie eine `while`-Schleife statt einer `for`-Schleife verwenden. Die Funktion sollte identische Ausgabe erzeugen – jede Zeile von `detention_message` beginnend bei `1` nummeriert.

Diese Übung zeigt, dass `for`-Schleifen und `while`-Schleifen oft austauschbar verwendet werden können, und hilft Ihnen zu erkennen, wann welches Muster geeigneter ist.

```python
## def detention_helper(detention_message, num_lines):
##     <FILL_IN>
```

##### Aufgabe 2.1 — `detention_helper()` mit einer While-Schleife neu schreiben — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
def detention_helper(detention_message, num_lines):
    i = 0
    while i < num_lines:
        i += 1
        print(f"{i}. {detention_message}")
```

</details>

### Aufgabe 2.2: Die While-Schleifen-Version aufrufen

Rufen Sie Ihre aktualisierte Funktion `detention_helper()` mit den Eingaben für Barts neues Nachsitzen auf. Überprüfen Sie, dass `"I will do my python homework"` 25-mal ausgegeben wird, wobei jede Zeile nummeriert ist.

```python
## detention_helper(<FILL_IN>, <FILL_IN>)
```

##### Aufgabe 2.2 — Die While-Schleifen-Version aufrufen — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
detention_helper("I will do my python homework", 25)
```

</details>

## Aufgabe 3: Mit Listen und Schleifen arbeiten

### Aufgabe 3.1: Die ursprüngliche tabellarische Ausgabe prüfen

Der Code unten zeigt eine Tabelle von Städten mit ihren jeweiligen Temperaturen und Luftfeuchtigkeiten an. Zuvor wurde dies mit sich wiederholenden Einzelvariablen geschrieben – eine pro Stadt.

```python
city1 = "San Francisco"
temp1 = 58
humidity1 = 0.85

city2 = "Paris"
temp2 = 75
humidity2 = 0.50

city3 = "Mumbai"
temp3 = 81
humidity3 = 0.88

print(f"{'City':15} {'Temperature':15} {'Humidity':15}")
print(f"{city1:15} {temp1:11} {humidity1:12.2f}")
print(f"{city2:15} {temp2:11} {humidity2:12.2f}")
print(f"{city3:15} {temp3:11} {humidity3:12.2f}")
```

### Aufgabe 3.2: Den Code mit Listen und einer While-Schleife refaktorieren

1. Geben Sie eine Tabellenüberschrift aus, in der `"City"`, `"Temperature"` und `"Humidity"` mit f-String-Formatierung auseinander platziert sind.
2. Refaktorieren Sie den Code, um **Listen** für Städtenamen, Temperaturen und Luftfeuchtigkeiten zu verwenden. Verwenden Sie eine **`while`-Schleife**, um durch die Listen zu iterieren und jede Zeile auszugeben, wobei die Ausgabe für die Ausrichtung und die Luftfeuchtigkeit auf zwei Nachkommastellen formatiert wird.

Dieser Ansatz skaliert sauber, wenn die Anzahl der Städte wächst, ohne zusätzliche Variablendeklarationen zu erfordern.

```python
## city_list = TODO
## temperature_list = TODO
## humidity_list = TODO

## Print the header row
## Eine while-Schleife verwenden, um jede Zeile auszugeben
```

##### Aufgabe 3.2 — Den Code mit Listen und einer While-Schleife refaktorieren — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
city_list = ["San Francisco", "Paris", "Mumbai"]
temperature_list = [58, 75, 81]
humidity_list = [.85, .5, .88]

print(f"{'City':15} {'Temperature':15} {'Humidity':15}")
i = 0
while (i < len(city_list)):
    print(f"{city_list[i]:15} {temperature_list[i]:11} {humidity_list[i]:12.2f}")
    i = i + 1
```

</details>

### Aufgabe 3.3: Die Funktion `item_count()` erstellen

Schreiben Sie eine Funktion namens `item_count`, die eine Liste von Werten akzeptiert und ein Dictionary zurückgibt, das die Anzahl enthält, wie oft jeder eindeutige Wert in der Liste vorkommt.

**Beispiel:**

```python
item_count(['a', 'b', 'a'])
# Returns: {'a': 2, 'b': 1}
```

**Zu berücksichtigende Schritte:**

1. Initialisieren Sie ein leeres Dictionary, um die Zählungen zu speichern.
2. Iterieren Sie durch jedes Element in der Eingabeliste.
3. Wenn das Element noch nicht im Dictionary ist, fügen Sie es mit einer Zählung von `1` hinzu.
4. Wenn das Element bereits existiert, erhöhen Sie seine Zählung um `1`.
5. Geben Sie das fertige Dictionary zurück.

```python
## def item_count(<FILL IN>):  
##    <FILL IN>
```

##### Aufgabe 3.3 — Die Funktion `item_count()` erstellen — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
def item_count(input_list):
    output_dict = {}  # Initialize an empty dictionary
  
    for item in input_list:
        if item not in output_dict:
            # Einen Eintrag für das Element mit einem Anfangszähler von 1 anlegen
            output_dict[item] = 1
        else:
            # 1 zum aktuellen Zähler des Elements addieren
            output_dict[item] += 1
      
    return output_dict
```

</details>

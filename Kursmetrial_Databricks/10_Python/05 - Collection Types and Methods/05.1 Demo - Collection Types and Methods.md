# Demo – Collection-Typen und Methoden

## Überblick

Diese Demo führt Pythons zentrale Collection-Datentypen ein – Listen, Dictionaries und Tupel – und die Methoden, die sie mächtig machen. 3. **Dictionaries erstellen und abfragen** mit Schlüssel-Wert-Zugriffsmustern und Dictionary-Methoden
4. **Tupel erstellen und darauf zugreifen** und beschreiben, wie sich ihre Unveränderlichkeit von Listen unterscheidet

## A. Objekte und Methoden

### A1. Was ist ein Objekt?

Ein [**Objekt**](https://www.w3schools.com/python/python_classes.asp) ist eine Instanz eines bestimmten Datentyps.

- **`1`** ist ein Integer-Objekt.
- **`"Hello"`** ist ein String-Objekt.

Jeder Wert, mit dem Sie in Python arbeiten, ist ein Objekt, und der Datentyp dieses Objekts bestimmt, welche Operationen und Methoden Ihnen zur Verfügung stehen.

### A2. Was ist eine Methode?

Datentypen stellen spezielle Funktionen namens [**Methoden**](https://www.w3schools.com/python/gloss_python_object_methods.asp) bereit, die zusätzliche Funktionalität bieten. Methoden sind wie reguläre Funktionen, aber sie werden **auf** einem Objekt mit der Punktnotation aufgerufen:

```
object.method_name(arguments)
```

Methoden können entweder:
- **Ein neues Objekt zurückgeben** – wobei das Original unverändert bleibt, oder
- **Das Objekt an Ort und Stelle ändern** – wobei das Original direkt geändert wird.

> **Hinweis:**
>
> Methoden sind Funktionen, die von einem Datentyp bereitgestellt werden und die Sie auf Objekten dieses Typs aufrufen. Sie wirken auf das Objekt, mit dem sie aufgerufen werden, und erlauben Ihnen, mehr von diesem Datentyp bereitgestellte Funktionalität zu nutzen.

### A3. String-Methoden

Strings stellen eine Methode namens [**`upper()`**](https://www.w3schools.com/python/ref_string_upper.asp) bereit, die eine großgeschriebene Kopie des Strings zurückgibt. Beachten Sie, dass die ursprüngliche Variable `greeting` nicht geändert wird – `upper()` gibt einen **neuen** String zurück, statt das Original an Ort und Stelle zu bearbeiten.

```python
greeting = "hello"
print(greeting.upper())
print(greeting)
```

### A4. In-Place- vs. Nicht-In-Place-Methoden

Wie oben gezeigt, ist `upper()` **keine** In-Place-Methode – sie gibt einen neuen String zurück und lässt `greeting` unverändert.

Einige Methoden **ändern** jedoch das Objekt, auf dem sie aufgerufen werden, direkt. Ein Beispiel dafür sehen Sie mit der Listen-Methode `append()` im nächsten Abschnitt.

Eine vollständige Referenz der String-Methoden finden Sie unter [W3Schools Python String Methods](https://www.w3schools.com/python/python_ref_string.asp).

## B. Listen

### B1. Eine Liste erstellen

Eine [Liste](https://www.w3schools.com/python/python_lists.asp) ist eine geordnete Folge von Elementen, definiert mit eckigen Klammern:

```
[item1, item2, item3, ...]
```

Elemente können von jedem Typ sein, wobei Listen in der Praxis typischerweise Werte desselben Typs halten. Das Beispiel unten erstellt eine Liste von Frühstücksartikeln.

```python
breakfast_list = ["pancakes", "eggs", "waffles"]
breakfast_list
```

```python
# Python can tell us breakfast_list's type
type(breakfast_list)
```

```python
# In einer Liste funktioniert jeder Datentyp
["hello", True, 1, 1.5]
```

### B2. Listen-Methoden

Eine der häufigsten Listen-Operationen ist das Hinzufügen eines neuen Elements. Listen stellen dafür die Methode [**`append()`**](https://www.w3schools.com/python/ref_list_append.asp) bereit.

`append()` nimmt einen beliebigen Wert als Argument und **ändert die Liste an Ort und Stelle**, indem der Wert am Ende hinzugefügt wird. Das ist ein Beispiel für eine **In-Place-Methode** – anders als `upper()` bei Strings ändert `append()` das ursprüngliche Listenobjekt direkt.

```python
breakfast_list.append("yogurt")
breakfast_list
```

```python
["pancakes", "eggs"] + ["waffles", "yogurt"]
```

> **Zu Listen hinzufügen**
>
> Die Methode `append()` ist eine In-Place-Operation. Sie gibt keine neue Liste zurück, sondern fügt das neue Element am Ende der Liste hinzu. Der Operator `+` ist für Listen ebenfalls als **Verkettung** definiert und erzeugt eine neue Liste, ohne eines der Originale zu ändern.

Sie können `+` auch verwenden, um Elemente anzuhängen, indem Sie das Ergebnis der Variablen wieder zuweisen. Eine Kurzform für dieses Muster ist der Operator `+=`, der Addition und Zuweisung in einem Schritt kombiniert.

Die zwei Zellen unten erzeugen identische Ergebnisse:

```python
breakfast_list = ["pancakes", "eggs", "waffles"]
breakfast_list = breakfast_list + ["yogurt"]
breakfast_list
```

```python
breakfast_list = ["pancakes", "eggs", "waffles"]
breakfast_list += ["yogurt"]
breakfast_list
```

Um die Anzahl der Elemente in einer Liste zu erhalten, verwenden Sie die eingebaute Funktion [**`len()`**](https://www.w3schools.com/python/ref_func_len.asp). Erinnern Sie sich aus dem vorherigen Modul, dass `len()` eine eingebaute Python-Funktion ist – hier wenden wir sie auf unsere `breakfast_list` an, um zu sehen, wie viele Elemente sie enthält.

```python
# Wie viele Elemente enthält breakfast_list?
len(breakfast_list)
```

### B3. Listen-Indexierung und -Slicing

Um auf ein bestimmtes Element in einer Liste zuzugreifen, verwenden Sie [Listen-Indexierung](https://www.w3schools.com/python/python_lists_access.asp):

```
list_name[index]
```

Python verwendet **nullbasierte Indexierung**, sodass das erste Element bei Index `0` liegt, das zweite bei `1` und so weiter. **Negative Indizes** zählen vom Ende der Liste, wobei `-1` auf das letzte Element verweist.

```python
# First element (index 0)
breakfast_list[0]
```

```python
# Last element (index -1)
breakfast_list[-1]
```

### B4. Auf einen Bereich von Elementen zugreifen

Um auf einen Bereich von Elementen zuzugreifen, verwenden Sie die folgende Slicing-Syntax:

```
list_name[start:stop:step]
```

Dies gibt eine neue Liste zurück, die Elemente von `start` bis – aber **ohne** – `stop` enthält. Das Weglassen von `start` bedeutet standardmäßig den Anfang der Liste; das Weglassen von `stop` bedeutet standardmäßig das Ende. `step` gibt an, wie viele Elemente zwischen den zu extrahierenden Elementen übersprungen werden.

```python
# Der Stopp-Index ist exklusiv – gibt die Elemente an Index 0 und 1 zurück
breakfast_list[0:2]
```

```python
# Skip every other element
breakfast_list[0:4:2]
```

```python
# Skip every other element
breakfast_list[::2]
```

```python
print(breakfast_list[:2])   # Vom Anfang bis Index 2 (exklusiv)
print(breakfast_list[1:])   # Von Index 1 bis zum Ende
```

### B5. Weitere Listen-Manipulation

1. Sie können eine Liste auch **umkehren**, indem Sie Slicing mit einem Schritt von `-1` verwenden.

```python
# Reverse the list
breakfast_list[::-1]
```

2. Sie können auch einen Wert an einem bestimmten Index **aktualisieren**, indem Sie ihm einen neuen Wert zuweisen. Der neue Wert ersetzt das vorhandene Element an diesem Index in der Liste.

```python
print(breakfast_list)
breakfast_list[0] = "sausage"
print(breakfast_list)
```

3. Verwenden Sie den Operator `in`, um zu prüfen, ob ein Element in einer Liste existiert. Dies gibt einen Boolean-Wert zurück: `True`, wenn das Element gefunden wird, und `False`, wenn nicht.
   - Zum Beispiel prüft `"waffles" in breakfast_list`, ob `"waffles"` eines der Elemente in `breakfast_list` ist.

```python
"waffles" in breakfast_list
```

## C. Dictionaries

### C1. Ein Dictionary erstellen

Ein [Dictionary](https://www.w3schools.com/python/python_dictionaries.asp) speichert Daten als eine Folge von **Schlüssel-Wert-Paaren**:

```
{key_1: value_1, key_2: value_2, ...}
```

Schlüssel und Werte können von jedem Typ sein. Da jeder Schlüssel auf genau einen Wert abbildet, **müssen alle Schlüssel eindeutig sein**.

```
rates = [
    {"currency": "GBP", "rate": 0.79},
    {"currency": "JPY", "rate": 149.50},
    {"currency": "EUR", "rate": 0.93},
]
```

Das Beispiel unten erstellt ein Dictionary, in dem die Schlüssel Namen von Frühstücksgerichten und die Werte die verzehrten Mengen sind.

```python
breakfast_dict = {"pancakes": 1, "eggs": 2, "waffles": 3}
breakfast_dict
```

### C2. Dictionary-Methoden

Dictionaries stellen mehrere nützliche [Methoden](https://www.w3schools.com/python/python_ref_dictionary.asp) bereit:

- **`get()`**: Gibt den einem gegebenen Schlüssel zugeordneten Wert zurück.
- **`keys()`**: Gibt eine Liste mit den Dictionary-Schlüsseln zurück.
- **`items()`**: Gibt eine Ansicht aller Schlüssel-Wert-Paare zurück.

Sie können auch die Klammernotation `dict_object[key]` verwenden, um auf Werte zuzugreifen.

```python
# Die Methode get() verwenden
breakfast_dict.get("waffles")
```

```python
# Using bracket notation
breakfast_dict["waffles"]
```

```python
# Die Methode keys() verwenden.  
breakfast_dict.keys()
```

```python
# Die Methode items() verwenden
breakfast_dict.items()
```

### C3. Ein Dictionary aktualisieren

Sie können ein Dictionary aktualisieren, indem Sie einem Schlüssel mit Klammernotation einen Wert zuweisen:

- Wenn der **Schlüssel bereits existiert**, wird der aktuelle Wert überschrieben.
- Wenn der **Schlüssel nicht existiert**, wird ein neues Schlüssel-Wert-Paar erstellt.

Das Beispiel unten aktualisiert die Waffel-Anzahl und fügt einen neuen Eintrag für Joghurt hinzu.

```python
print(breakfast_dict)
breakfast_dict["waffles"] += 1
breakfast_dict["yogurt"] = 1
print(breakfast_dict)
```

> **Hinweis:**
>
> `+=` wird verwendet, um die Waffel-Anzahl zu erhöhen, weil der Schlüssel `"waffles"` bereits im Dictionary existiert.
>
> `"yogurt"` wird direkt mit `= 1` zugewiesen, weil es ein neuer Schlüssel ist – `+=` auf einem Schlüssel, der noch nicht existiert, würde einen `KeyError` auslösen.

### C4. Auf Schlüssel prüfen

Verwenden Sie die Methode [**`keys()`**](https://www.w3schools.com/python/ref_dictionary_keys.asp), um alle Schlüssel in einem Dictionary abzurufen, und verwenden Sie dann den Operator `in`, um zu prüfen, ob ein bestimmter Schlüssel vorhanden ist.

```python
print(breakfast_dict.keys())
print("bacon" in breakfast_dict.keys())
```

## D. Tupel

### D1. Ein Tupel erstellen

Ein [Tupel](https://www.w3schools.com/python/python_tuples.asp) ist eine geordnete Folge von Elementen, ähnlich einer Liste, aber **unveränderlich (immutable)** – einmal erstellt, kann sein Inhalt nicht geändert werden. Tupel werden mit runden Klammern definiert:

```
(item1, item2, item3, ...)
```

Tupel können Elemente jedes Typs enthalten und bewahren die Einfügereihenfolge.

```python
breakfast_tuple = ("pancakes", "eggs", "waffles")
breakfast_tuple
```

### D2. Tupel-Operationen

Da Tupel unveränderlich sind, unterstützen sie keine Methoden wie `append()`. Sie können jedoch weiterhin **Indexierung**, **Slicing** und den Operator **`in`** verwenden – dieselben Muster, die Sie bei Listen verwendet haben.

Die Tabelle unten fasst die wesentlichen Unterschiede zwischen Listen, Dictionaries und Tupeln zusammen:

| Merkmal | Liste | Dictionary | Tupel |
|---|---|---|---|
| Geordnet | Ja | Ja (Python 3.7+) | Ja |
| Veränderlich | Ja | Ja | Nein |
| Indexiert nach | Integer-Position | Schlüssel | Integer-Position |
| Erlaubt Duplikate | Ja | Schlüssel müssen eindeutig sein | Ja |
| Definiert mit | `[ ]` | `{ }` | `( )` |

```python
# Auf das erste Element per Index zugreifen
breakfast_tuple[0]
```

```python
# Slice a range of elements
breakfast_tuple[1:3]
```

```python
# Check for element membership
print("pancakes" in breakfast_tuple)
```

## E. Fazit

In dieser Demo haben Sie Pythons zentrale Collection-Datentypen und die Methoden, die sie antreiben, erkundet. Wichtige Erkenntnisse:

1. Ein **Objekt** ist eine Instanz eines Datentyps, und **Methoden** sind Funktionen, die von diesem Typ bereitgestellt und mit der Punktnotation aufgerufen werden.
2. Methoden können **In-Place** (das ursprüngliche Objekt ändernd) oder **Nicht-In-Place** (ein neues Objekt zurückgebend) sein.
3. **Listen** sind geordnete, veränderliche Folgen, die `append()`, Indexierung, Slicing und `in`-Prüfungen unterstützen.
4. **Dictionaries** speichern Schlüssel-Wert-Paare und unterstützen `get()`, Klammerzugriff, Schlüssel-Aktualisierungen und `keys()` für Enthaltensprüfungen.
5. **Tupel** sind geordnet und unveränderlich – sie unterstützen Indexierung, Slicing und `in`-Prüfungen, können aber nach der Erstellung nicht geändert werden.

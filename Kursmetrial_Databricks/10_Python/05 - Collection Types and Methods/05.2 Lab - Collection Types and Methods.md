## Aufgabe 1: Mit Listen arbeiten

### Aufgabe 1.1: Eine Abendessen-Liste erstellen

Erstellen Sie eine Liste namens **`dinner_list`**, die die Elemente `"potatoes"`, `"peppers"` und `"onions"` in dieser Reihenfolge enthält. Geben Sie dann die Abendessen-Liste aus.

```python
## dinner_list = TODO
```

##### Aufgabe 1.1 — Eine Abendessen-Liste erstellen — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
dinner_list = ["potatoes", "peppers", "onions"]
print(dinner_list)
```

</details>

### Aufgabe 1.2: Ein Listen-Element aktualisieren

Es stellt sich heraus, dass wir eigentlich Süßkartoffeln gegessen haben, nicht normale Kartoffeln. Aktualisieren Sie das erste Element von **`dinner_list`** zu `"sweet potatoes"`.

Sie können ein Listen-Element aktualisieren, indem Sie seiner Indexposition einen neuen Wert zuweisen: `list[index] = new_value`. Geben Sie die Liste nach der Aktualisierung aus.

```python
## dinner_list[0] = TODO
```

##### Aufgabe 1.2 — Ein Listen-Element aktualisieren — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python

print(dinner_list)
```

</details>

### Aufgabe 1.3: An eine Liste anhängen

Wir hatten auch etwas Reis zum Abendessen. Verwenden Sie die Methode **`.append()`**, um `"rice"` am Ende von **`dinner_list`** hinzuzufügen.

Die Methode `.append()` ändert die Liste an Ort und Stelle und fügt das neue Element als letztes Element hinzu. Geben Sie die Abendessen-Liste nach dem Anhängen aus.

```python
## dinner_list = TODO
```

##### Aufgabe 1.3 — An eine Liste anhängen — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
dinner_list.append("rice")
print(dinner_list)
```

</details>

## Aufgabe 2: Mit Dictionaries arbeiten

### Aufgabe 2.1: Ein Abendessen-Dictionary erstellen

Erstellen Sie ein Dictionary namens **`dinner_dict`**, das jedes Gericht auf die gegessene Menge abbildet. Verwenden Sie die folgenden Schlüssel-Wert-Paare:

| Schlüssel | Wert |
| --- | --- |
| `"sweet potatoes"` | `3` |
| `"peppers"` | `4` |
| `"onions"` | `1` |

Dictionaries werden mit geschweiften Klammern `{}` mit `key: value`-Paaren definiert, die durch Kommas getrennt sind. Nachdem Sie das Abendessen-Dictionary erstellt haben, geben Sie es aus.

```python
## dinner_dict = TODO
```

##### Aufgabe 2.1 — Ein Abendessen-Dictionary erstellen — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
dinner_dict = {"sweet potatoes": 3, "peppers": 4, "onions": 1}
print(dinner_dict)
```

</details>

### Aufgabe 2.2: Ein Dictionary aktualisieren

Nach weiterer Überlegung stellen wir fest, dass wir nur `2` Süßkartoffeln hatten – und wir hatten auch `1` Eis (sagen Sie es niemandem).

Aktualisieren Sie **`dinner_dict`**, um beide Änderungen widerzuspiegeln:
* Ändern Sie den Wert für `"sweet potatoes"` zu `2`
* Fügen Sie einen neuen Schlüssel `"ice cream"` mit dem Wert `1` hinzu

Sie können ein Schlüssel-Wert-Paar mit der Zuweisungssyntax aktualisieren oder hinzufügen: `dict[key] = value`. Nachdem Sie das Abendessen-Dictionary aktualisiert haben, geben Sie es aus.

```python
## dinner_dict = TODO
```

##### Aufgabe 2.2 — Ein Dictionary aktualisieren — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
dinner_dict["sweet potatoes"] = 2
dinner_dict["ice cream"] = 1
print(dinner_dict)
```

</details>

## Aufgabe 3: Mit Sets arbeiten

Ein Set ist eine ungeordnete Collection eindeutiger Elemente. Anders als Listen erlauben Sets keine doppelten Werte und behalten keine Einfügereihenfolge bei. Sets sind besonders nützlich für Enthaltensprüfungen und mathematische Operationen wie Vereinigung, Schnittmenge und Differenz.

> **Python-Dokumentation**
>
> Sehen Sie sich die offizielle [Python-Dokumentation zu Sets](https://docs.python.org/3/tutorial/datastructures.html#sets) an, um verfügbare Methoden und Operationen zu erkunden, während Sie diesen Abschnitt abschließen.

### Aufgabe 3.1. Zutaten-Sets erstellen und die Schnittmenge finden

Erstellen Sie die folgenden drei Sets von Zutaten:

| Variable | Zutaten |
| --- | --- |
| **`ingredient_set_1`** | `"carrots"`, `"onions"`, `"potatoes"` |
| **`ingredient_set_2`** | `"broccoli"`, `"carrots"`, `"rice"` |
| **`ingredient_set_3`** | `"sweet potatoes"`, `"carrots"`, `"corn"` |

Erstellen Sie dann programmatisch ein neues Set namens **`ingredient_intersection_set`**, das nur die Zutaten enthält, die in **allen drei** Sets vorkommen.

Verwenden Sie den Operator `&`, um die Schnittmenge mehrerer Sets zu berechnen: `set_a & set_b & set_c`.

```python
## ingredient_set_1 = TODO
## ingredient_set_2 = TODO
## ingredient_set_3 = TODO
## ingredient_intersection_set = TODO
```

##### Aufgabe 3.1 — Zutaten-Sets erstellen und die Schnittmenge finden — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
ingredient_set_1 = {"carrots", "onions", "potatoes"}
ingredient_set_2 = {"broccoli", "carrots", "rice"}
ingredient_set_3 = {"sweet potatoes", "carrots", "corn"}
ingredient_intersection_set = ingredient_set_1 & ingredient_set_2 & ingredient_set_3
ingredient_intersection_set
```

</details>

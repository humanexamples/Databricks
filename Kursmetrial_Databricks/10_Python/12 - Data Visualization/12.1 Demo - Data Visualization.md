## C. Pandas-Plotting

### C1. Histogramm mit `hist()`

`pandas` stellt eingebaute Plotting-Methoden bereit, die direkt auf einer `Series` oder einem `DataFrame` aufgerufen werden können. Die Methode `hist()` generiert ein Histogramm, das nützlich ist, um die Verteilung einer numerischen Spalte zu verstehen.

Die folgende Zelle erstellt ein Histogramm der Spalte `bedrooms`:

```python
df["bedrooms"].hist()
```

### C2. Histogramm-Bins anpassen

Sie können die Granularität eines Histogramms steuern, indem Sie die Anzahl der Bins mit dem Parameter `bins` angeben. Das Erhöhen der Anzahl der Bins bietet eine feinere Sicht auf die Verteilung.

**Binning** teilt den Datenbereich in Intervalle (Bins) auf und zählt, wie viele Werte in jeden Bin fallen. Das Setzen des Parameters `bins` auf eine Zahl (z. B. `bins=10`) weist pandas an, die Daten in so viele Intervalle aufzuteilen.

Zum Beispiel:

`df["bedrooms"].hist(bins=10)`

erstellt ein Histogramm mit 10 Bins, das zeigt, wie die Werte von `bedrooms` über diese Intervalle verteilt sind.

```python
df["bedrooms"].hist(bins=20)
```

### C3. Box-Plot mit `boxplot()`

Die Methode `boxplot()` auf einem `DataFrame` erstellt einen Box-Plot für eine oder mehrere angegebene Spalten. Box-Plots sind nützlich, um die Streuung, den Median und Ausreißer einer numerischen Variablen zu visualisieren.

Die folgende Zelle erstellt nebeneinanderstehende Box-Plots für `bedrooms` und `bathrooms`:

```python
df.boxplot(["bedrooms", "bathrooms"])
```

Die Boxplot-Ausgabe zeigt die Verteilung der Spalten `bedrooms` und `bathrooms`. Jede Box zeigt den Median (Mittellinie), den Interquartilsbereich (Boxkanten) und potenzielle Ausreißer (Punkte außerhalb der Whiskers). Die Whiskers erstrecken sich bis zu den Minimal- und Maximalwerten innerhalb des 1,5-Fachen des Interquartilsbereichs. Ausreißer werden als einzelne Punkte dargestellt. Diese Visualisierung hilft, die Streuung, die zentrale Tendenz und das Vorhandensein von Ausreißern für jede Variable zu identifizieren.

## D. Seaborn-Visualisierungen

### D1. Einführung in Seaborn

[seaborn](https://seaborn.pydata.org/) ist eine weit verbreitete Python-Datenvisualisierungsbibliothek, die auf `matplotlib` aufbaut. Sie integriert sich nativ mit `pandas`-DataFrames und erzeugt Visualisierungen in Publikationsqualität mit minimaler Konfiguration.

Importieren Sie `seaborn` mit dem konventionellen Alias `sns`:

> **Seaborn und Databricks**
>
> `seaborn` ist auf Databricks-Clustern vorinstalliert und erfordert keinen separaten Installationsschritt. Es kann direkt in jeder Notebook-Zelle importiert werden.

```python

```

### D2. Streudiagramm mit `scatterplot()`

Die Funktion `sns.scatterplot()` erstellt ein Streudiagramm aus einem `pandas`-DataFrame. Sie geben den DataFrame mit dem Parameter `data` und die Spaltennamen für die x- und y-Achse an.

Die folgende Zelle stellt `bedrooms` auf der x-Achse und `bathrooms` auf der y-Achse dar, um die Beziehung zwischen den beiden Variablen zu erkunden:

```python
sns.scatterplot(data=df, x="bedrooms", y="bathrooms")
```

### D3. Regressionsdiagramm mit `regplot()`

Die Funktion `sns.regplot()` akzeptiert dieselben Parameter wie `scatterplot()`, überlagert aber zusätzlich eine Ausgleichsgerade (lineare Regressionsgerade) auf dem Streudiagramm. Das ist nützlich, um die Stärke und Richtung einer linearen Beziehung zwischen zwei Variablen visuell zu bewerten.

```python
sns.regplot(data=df, x="bedrooms", y="bathrooms")
```

### D4. Anpassungsgüte mit Regression bestimmen

Um zu bestimmen, wie gut die Beziehung zwischen der Anzahl der Schlafzimmer und der Anzahl der Badezimmer zu einer Regressionsgeraden passt, quantifiziert der **Pearson-Korrelationskoeffizient (r)** die Stärke und Richtung der linearen Beziehung zwischen diesen beiden Variablen.

Sie können den r-Wert mit `scipy.stats.pearsonr()` berechnen:

```python
from scipy import stats

r_value, p_value = stats.pearsonr(df["x_column"], df["y_column"])
```

Die Funktion gibt sowohl den Korrelationskoeffizienten (`r_value`) als auch den p-Wert (`p_value`) zurück, der die statistische Signifikanz angibt.

#### Den r-Wert interpretieren

| r-Wert-Bereich | Stärke | Interpretation |
| --- | --- | --- |
| 0,90 bis 1,00 | Sehr stark positiv | Variablen steigen sehr konsistent gemeinsam an |
| 0,70 bis 0,89 | Stark positiv | Klarer positiver linearer Trend |
| 0,40 bis 0,69 | Mäßig positiv | Erkennbarer positiver Trend mit Streuung |
| 0,20 bis 0,39 | Schwach positiv | Leichter positiver Trend, erhebliche Streuung |
| -0,19 bis 0,19 | Sehr schwach / keine | Keine bedeutsame lineare Beziehung |
| -0,39 bis -0,20 | Schwach negativ | Leichter negativer Trend |
| -0,69 bis -0,40 | Mäßig negativ | Erkennbarer negativer Trend mit Streuung |
| -0,89 bis -0,70 | Stark negativ | Klarer negativer linearer Trend |
| -1,00 bis -0,90 | Sehr stark negativ | Variablen bewegen sich sehr konsistent gegenläufig |

> **Hinweis:**
>
> Der r-Wert misst nur **lineare** Beziehungen. Ein niedriger r bedeutet nicht zwangsläufig, dass keine Beziehung existiert – sie könnte nicht-linear sein.

```python
from scipy import stats

# Zeilen mit fehlenden Werten in einer der beiden Spalten entfernen
clean_df = df[["bedrooms", "bathrooms"]].dropna()

# Calculate the Pearson correlation coefficient
r_value, p_value = stats.pearsonr(clean_df["bedrooms"], clean_df["bathrooms"])

print(f"Pearson correlation coefficient (r): {r_value:.4f}")
print(f"P-value: {p_value:.2e}")
print(f"\nInterpretation: {'Strong' if abs(r_value) >= 0.7 else 'Moderate' if abs(r_value) >= 0.4 else 'Weak'} {'positive' if r_value > 0 else 'negative'} linear relationship")
```

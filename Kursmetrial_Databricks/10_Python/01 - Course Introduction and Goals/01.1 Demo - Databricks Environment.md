# Demo – Die Databricks-Umgebung

## Überblick

Diese Demo führt durch die grundlegende Mechanik der Arbeit in einem Databricks-Notebook. Sie beginnen damit, sich mit einer Compute-Ressource zu verbinden, führen dann Ihre erste Python-Zelle aus, erkunden den Magic-Befehl `%md` zum Rendern von formatiertem Markdown und schließen mit einem Überblick über das Databricks-Dokumentations-Ökosystem ab. Jeder Abschnitt baut eine praktische Fähigkeit auf, die Sie im weiteren Verlauf dieses Kurses verwenden werden.

## Lernziele

Am Ende dieser Demonstration können Sie:

1. **Eine Compute-Umgebung auswählen**, indem Sie ein Notebook an Serverless Compute anhängen
2. **Code in einem Notebook ausführen** über Tastaturkürzel und das Zell-Ausführungsmenü
3. **Den Magic-Befehl `%md` verwenden**, um formatierten Markdown-Inhalt zu rendern
4. **In der Databricks-Dokumentation navigieren**, um Plattformfunktionen eigenständig zu erkunden

## B. Code in einem Notebook ausführen

### B1. Eine Zelle ausführen

Jedes Notebook legt eine Standardsprache fest – in diesem Fall **Python**. Führen Sie die Zelle unten mit einer der folgenden Optionen aus:

- **STRG+EINGABE** oder **CMD+RETURN** — führt die aktuelle Zelle aus und bleibt darauf
- **UMSCHALT+EINGABE** oder **SHIFT+RETURN** — führt die aktuelle Zelle aus und wechselt zur nächsten Zelle
- Die Option **Run Cell** aus dem Zell-Aktionsmenü (▶-Symbol oben links in der Zelle)

Sie können den String in der Zelle unten vor dem Ausführen gerne ändern.

```python
print("I'm running Python!")
```

## C. Magic-Befehle

### C1. Der Magic-Befehl `%md`

Der Magic-Befehl `%md` weist Databricks an, den Inhalt einer Zelle als **Markdown** zu rendern, statt ihn als Code auszuführen. Markdown ist eine leichtgewichtige Auszeichnungssprache zum Erstellen von formatiertem Text.

Um zu erkunden, wie Markdown in einer Zelle funktioniert:

1. Doppelklicken Sie auf die gerenderte Zelle unten, um in den Bearbeitungsmodus zu wechseln und den rohen Markdown-Quelltext zu sehen.
2. Drücken Sie **`Esc`**, um den Bearbeitungsmodus zu verlassen und zur gerenderten Ansicht zurückzukehren.

> **Markdown-Rendering**
>
> Databricks rendert Markdown-Zellen automatisch, wenn Sie den Bearbeitungsmodus verlassen. Die rohe Syntax (z. B. `**fett**`, `# Überschrift`) wird durch formatierte Ausgabe ersetzt, die für alle Notebook-Betrachter sichtbar ist.

Die folgende Zelle demonstriert gängige Markdown-Syntaxelemente, die in Databricks-Notebooks unterstützt werden:

```markdown
# Überschrift Eins
## Überschrift Zwei
### Überschrift Drei

Dies ist ein Test des Notfall-Rundfunksystems. Dies ist nur ein Test.

Dies ist Text mit einem **fetten** Wort darin.

Dies ist Text mit einem *kursiven* Wort darin.

Dies ist eine geordnete Liste

1. eins
2. zwei
3. drei

Dies ist eine ungeordnete Liste

- Äpfel
- Pfirsiche
- Bananen

Links/eingebettetes HTML: <a href="https://www.markdownguide.org/getting-started/" target="_blank">Was ist Markdown?</a>

Und natürlich Tabellen:

| Name  | Alter | Rasse            |
|-------|-------|------------------|
| Buddy | 2     | Golden Retriever |
| Bingo | 10    | Border Collie    |
| Momo  | 3     | Labrador         |
```

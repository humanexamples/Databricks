# Demo – Klassen

## Überblick

Diese Demo führt Python-Klassen ein, ein grundlegendes Konzept der objektorientierten Programmierung (OOP). Klassen bieten eine Vorlage zum Erstellen von Objekten, die Daten (Attribute) und Verhalten (Methoden) kombinieren. Sie lernen, wie man Klassen definiert und instanziiert, Instanzattribute verwendet und Methoden hinzufügt, um Funktionalität zu kapseln. Das Notebook behandelt außerdem den Unterschied zwischen Funktionen und Methoden. Sie sehen, wie Vererbung es Ihnen erlaubt, neue Klassen zu erstellen, die das Verhalten bestehender Klassen wiederverwenden und erweitern, was modularen und wartbaren Code für Data Engineering und Data Science unterstützt.

## Lernziele

Am Ende dieser Demonstration können Sie:

1. **Benutzerdefinierte Klassen definieren und instanziieren** in Python
2. **Daten speichern und darauf zugreifen** mit Instanzattributen und der `__init__`-Methode
3. **Methoden hinzufügen und aufrufen**, um Verhalten innerhalb einer Klasse zu kapseln
4. **Die Rolle von `self` verstehen** in Methoden und wie es die Objektinstanz referenziert
5. **Zwischen Funktionen und Methoden unterscheiden** in Python

## A. Einführung in Klassen

### A1. Was ist eine Klasse?

Von [W3Schools](https://www.w3schools.com/python/python_classes.asp):

> *Python ist eine objektorientierte Programmiersprache. Fast alles in Python ist ein Objekt mit seinen Eigenschaften und Methoden. Eine Klasse ist wie ein Objekt-Konstruktor oder eine „Vorlage" (Blueprint) zum Erstellen von Objekten.*

Beim Arbeiten mit Funktionen können Sie dieselbe Logik wiederverwenden, indem Sie verschiedene Argumente übergeben. **Klassen gehen einen Schritt weiter – sie bieten eine wiederverwendbare Vorlage sowohl für Code als auch für Daten.**

Sie haben bereits mit Pythons eingebauten Typen wie `int`, `str` und `list` gearbeitet. Sie können auch Ihre eigenen benutzerdefinierten [**Klassen**](https://peps.python.org/pep-0008/#class-names) definieren, um Konzepte der realen Welt zu modellieren.

Um eine Klasse zu definieren, verwenden Sie die folgende Syntax:

```python
class ClassName():
    <code block>
```

Anders als Variablen und Funktionen, die `snake_case` verwenden, folgen Klassennamen der Konvention des [Python-Style-Guides (PEP 8)](https://peps.python.org/pep-0008/) von `CapWords` – jedes Wort großgeschrieben, ohne Leerzeichen.

**HINWEIS:** Das Schlüsselwort `pass` weist Python an, nichts zu tun. Im Beispiel unten definieren wir eine `Dog`-Klasse, die gültig ist, aber noch kein Verhalten hat.

```python
# Den Bauplan erstellen
class Dog():
    pass
```

### A2. Eine Klasse instanziieren

Für eingebaute Typen wie `int` oder `str` erstellt Python automatisch Objekte, wenn Sie einen Literalwert wie `1` oder `"hello"` schreiben. Für benutzerdefinierte Klassen müssen Sie ein Objekt explizit mit der folgenden Syntax erstellen:

```python
object_name = ClassName()
```

Dieser Vorgang wird **Instanziierung** genannt – Sie erstellen eine bestimmte Instanz der Klasse. Unten instanziieren wir die `Dog`-Klasse und weisen sie der Variablen `my_dog` zu.

```python
# Den Bauplan instanziieren und in der Variablen speichern
my_dog = Dog()

type(my_dog)
```

### A3. Funktionen sind Objekte

In Python sind **Funktionen First-Class-Objekte** – genau wie Integer, Strings und Listen. Das bedeutet, Sie können eine Funktion einer Variablen zuweisen, sie als Argument übergeben oder sie in einer Datenstruktur speichern.

Wenn Sie eine Funktion einer Variablen zuweisen, verwenden Sie den Funktionsnamen **ohne Klammern**. Klammern würden die Funktion *aufrufen*; ohne sie referenzieren Sie das Funktionsobjekt selbst.

```python
my_variable = some_function   # assign the function (no parentheses)
my_variable()                 # über den neuen Namen aufrufen
```

```python
# Define a simple function
def greet(name):
    return f"Hello, {name}!"

# Die Funktion einer neuen Variablen zuweisen (keine Klammern!)
say_hello = greet

# Jetzt verweisen beide Namen auf dieselbe Funktion
print(say_hello("Rex"))   # Hello, Rex!
print(greet("Rex"))       # Hello, Rex
print(type(say_hello))    # <class 'function'>
```

## B. Code-Wiederverwendung mit Methoden

### B1. Methoden in einer Klasse definieren

Da wir nun ein `Dog`-Objekt erstellen können, fügen wir etwas Funktionalität hinzu. Verhalten in einer Klasse wird mit [**Methoden**](https://www.w3schools.com/python/gloss_python_object_methods.asp) definiert – speziellen Funktionen, die zur Klasse gehören und auf einem Objekt aufgerufen werden:

```python
object.method(args)
```

Eine Methode zu definieren ähnelt dem Definieren einer regulären Funktion, mit zwei wesentlichen Unterschieden:

1. Die Methodendefinition ist **innerhalb der Klassendefinition verschachtelt**.
2. Der erste Parameter muss immer **`self`** sein, gefolgt von zusätzlichen Parametern.

Die allgemeine Struktur sieht so aus:

```python
class ClassName():

    def method_name(self, args):
        method code
```

Im Beispiel unten definieren wir eine Methode `return_name`, die einen Namen akzeptiert und ihn als formatierten String zurückgibt. Der `self`-Parameter wird im nächsten Abschnitt erklärt.

```python
class UpdatedDog():
    
    def return_name(self, name):
        return f"name: {name}"
```

#### B1.1 Ist es eine Funktion oder eine Methode? Was ist der Unterschied?

Sie werden bemerken, dass Methoden Funktionen sehr ähnlich sehen. Das liegt daran, dass **eine Methode *eine* Funktion ist** – sie lebt nur innerhalb einer Klasse und wird auf einem Objekt aufgerufen.

| | Funktion | Methode |
| --- | --- | --- |
| **Definiert mit** | `def func_name(args):` | `def method_name(self, args):` |
| **Aufgerufen mit** | `func_name(args)` | `object.method_name(args)` |
| **Gehört zu** | Dem globalen Scope (oder einem Modul) | Einer bestimmten Klasse |
| **Zugriff auf Objektdaten?** | Nein (außer explizit übergeben) | Ja, über `self` |

Kurz gesagt: Wenn eine Funktion innerhalb einer Klasse definiert wird und `self` als ersten Parameter erhält, nennen wir sie eine **Methode**.

### B2. Eine Methode auf einem Objekt aufrufen

Mit der definierten `UpdatedDog`-Klasse können wir sie instanziieren und die Methode aufrufen. Beachten Sie, dass wir **kein** Argument für den `self`-Parameter übergeben – Python übernimmt das automatisch.

```python
my_updated_dog = UpdatedDog()

my_updated_dog.return_name("Rex")
```

### B3. `self` verstehen

Eine Methode unterscheidet sich von einer eigenständigen Funktion darin, dass sie auf das bestimmte Objekt wirken kann, auf dem sie aufgerufen wurde. Der `self`-Parameter ist die Art, wie die Methode dieses Objekt referenziert.

Wenn Sie `object.method()` aufrufen, übergibt Python automatisch das Objekt selbst als erstes Argument an `self`. Das bedeutet, `self` verweist immer auf die Instanz, die die Methode aufgerufen hat, unabhängig davon, wie Sie die Variable benannt haben.

Das Beispiel unten demonstriert das, indem es das Objekt sowohl direkt als auch über `self` innerhalb einer Methode ausgibt – sie sind dasselbe.

```python
class DogWithSelf():
    
    def print_self(self):
        print(self)
        
dog_with_self = DogWithSelf()

print(dog_with_self)
dog_with_self.print_self() # prints the same object
```

Beachten Sie, dass die direkte Ausgabe von `dog_with_self` und der Aufruf von `print_self()` darauf dieselbe Ausgabe erzeugen. Das liegt daran, dass `dog_with_self` als Argument an `self` innerhalb von `print_self()` übergeben wird.

## C. Daten-Caching mit Attributen

### C1. Die `__init__`-Methode und Instanzattribute

Zusätzlich zu Methoden brauchen Klassen eine Möglichkeit, Daten zu speichern. **Wenn eine Variable auf einer Klasseninstanz gespeichert wird, wird sie Attribut genannt.** Jede Instanz einer Klasse hat ihre eigene Kopie der Attribute, gesetzt auf ihre eigenen Werte.

Python bietet eine spezielle Methode namens **`__init__(self)`**, die automatisch aufgerufen wird, wenn ein Objekt erstellt wird. Diese ist als *Konstruktor-Methode* bekannt, weil sie die Attribute des Objekts im Moment der Instanziierung initialisiert.

Die allgemeine Struktur lautet:

```python
class ClassName():

    def __init__(self, arg):
        self.arg = arg
```

Im Beispiel unten speichert jedes `DogWithAttributes`-Objekt seine eigenen `name`- und `color`-Werte. Die `print`-Anweisung innerhalb von `__init__` bestätigt, dass der Konstruktor automatisch läuft, wenn das Objekt erstellt wird.

```python
class DogWithAttributes():

    def __init__(self, name, color):
        print("This ran automatically!")
        self.name = name
        self.color = color

dog_with_attributes = DogWithAttributes("Rex", "Orange")
```

### C2. Auf Attribute zugreifen

Als `__init__()` lief, speicherte es die Werte in `self` und band sie an die bestimmte Instanz. Sie können auf ein Attribut mit der Punktnotation zugreifen – ähnlich dem Aufruf einer Methode, aber **ohne Klammern**.

```python
dog_with_attributes.name
```

### C3. Attribute innerhalb von Methoden verwenden

Innerhalb jeder Methodendefinition können Sie auf die Attribute des Objekts mit `self.attribute_name` zugreifen. Da `self` immer auf die aufrufende Instanz verweist, funktioniert das korrekt, unabhängig davon, welcher Variablenname bei der Instanziierung verwendet wurde.

Das Beispiel unten kombiniert Attribute und eine Methode, um den gespeicherten Namen und die Fellfarbe des Hundes zurückzugeben.

```python
class DogWithAttributesAndMethod():
    
    def __init__(self, name, color):
        self.name = name
        self.color = color
        
    def return_name(self):
        return self.name

    def return_color(self):
        return self.color
    
my_dog = DogWithAttributesAndMethod("Rex", "tan")

print(f"My dog's name is {my_dog.return_name()} and his coat color is {my_dog.return_color()}")
```

### C4. Attribute mit Methoden aktualisieren

Attribute sind nicht fest – sie können jederzeit aktualisiert werden. Eine Methode kann ein Attribut ändern, indem sie `self.attribute_name` einem neuen Wert zuweist. Unten ändert `update_name` den gespeicherten Namen des Hundes, und `return_name` bestätigt die Änderung.

```python
class DogWithAttributesAndMethods():
    
    def __init__(self, name, color):
        self.name = name
        self.color = color
        
    def return_name(self):
        return self.name
        
    def update_name(self, new_name):
        self.name = new_name
        
my_dog = DogWithAttributesAndMethods("Rex", "tan")
print(f"Here's my dog's name: {my_dog.return_name()}")

my_dog.update_name("Ruffles")
print(f"My dog's name after updating it, is: {my_dog.return_name()}")
```

## D. Fortgeschrittenere Klassen

### D1. Interaktion mit anderen Klasseninstanzen

Klassen können viele Methoden und Attribute haben. Sie können auch mit anderen Instanzen derselben Klasse interagieren, indem sie sie als Methodenargumente akzeptieren.

In der `DogFinal`-Klasse unten akzeptiert die Methode `return_both_names` ein anderes `Dog`-Objekt als Argument und greift direkt auf dessen `name`-Attribut zu. Dieses Muster demonstriert, wie Klasseninstanzen zusammengesetzt und zusammen verwendet werden können, um komplexeres Verhalten zu bauen.

```python
class DogFinal():
    
    def __init__(self, name_str, color_str):
        self.name = name_str
        self.color = color_str
        
    def return_name(self):
        return self.name
        
    def update_name(self, new_name):
        self.name = new_name
        
    def return_both_names(self, other_dog_object):
        return self.name + " and " + other_dog_object.name
        
dog_1 = DogFinal("Rex", "tan")
dog_2 = DogFinal("Ruffles", "black and tan")

dog_1.return_both_names(dog_2)
```

### D2. Vererbung

**Vererbung** erlaubt es Ihnen, eine neue Klasse (**Child** oder **Subklasse** genannt) zu erstellen, die automatisch alle Attribute und Methoden einer bestehenden Klasse (**Parent** oder **Superklasse** genannt) erhält. Die Child-Klasse kann dann neues Verhalten hinzufügen oder bestehendes Verhalten überschreiben, ohne den Parent zu ändern.

Das ist nützlich, wenn Sie ein allgemeines Konzept haben (z. B. `Animal`) und spezifischere Versionen davon erstellen möchten (z. B. `Dog`, `Cat`), die gemeinsame Logik teilen, sich aber in bestimmten Details unterscheiden.

Die Syntax für Vererbung lautet:

```python
class ChildClass(ParentClass):
    <code block>
```

Sie übergeben den Namen der Parent-Klasse innerhalb der Klammern der Child-Klassendefinition. Das Child erbt alles vom Parent und kann:
- Parent-Methoden und -Attribute **unverändert verwenden**
- Parent-Methoden **überschreiben**, indem es sie neu definiert
- Den Parent mit neuen Methoden oder Attributen **erweitern**

Verwenden Sie `super().__init__()` innerhalb des `__init__` des Childs, um den Konstruktor des Parents aufzurufen und geerbte Attribute zu initialisieren.

```python
# Parent class
class Animal():
    def __init__(self, name, sound):
        self.name = name
        self.sound = sound

    def speak(self):
        return f"{self.name} says {self.sound}!"

# Child class inherits from Animal
class Dog(Animal):
    def __init__(self, name, color):
        super().__init__(name, sound="Woof")  # Call parent's __init__
        self.color = color                    # Neues Attribut hinzufügen

    def fetch(self):
        return f"{self.name} fetches the ball!"

# Child class with different default sound
class Cat(Animal):
    def __init__(self, name):
        super().__init__(name, sound="Meow")

# Demonstrate inheritance
my_dog = Dog("Rex", "tan")
my_cat = Cat("Whiskers")


print(my_dog.speak())   # Inherited method from Animal
print(my_dog.fetch())   # Neue Methode nur in Dog
print(my_cat.speak())   # Inherited method with different sound
print(type(my_dog))     # <class '__main__.Dog'>
```

## E. Fazit

In dieser Demo haben Sie die Kernkonzepte von Python-Klassen erkundet:

1. Eine **Klasse** ist eine Vorlage zum Erstellen von Objekten, die Daten und Verhalten zusammen bündeln.
2. Objekte werden erstellt, indem eine Klasse mit `ClassName()` **instanziiert** wird.
3. **Methoden** sind Funktionen, die innerhalb einer Klasse definiert werden und über den `self`-Parameter auf dem Objekt operieren.
4. Die Konstruktor-Methode **`__init__`** läuft automatisch, wenn ein Objekt erstellt wird, und wird verwendet, um Instanzattribute zu initialisieren.
5. **Attribute** speichern Daten auf jeder Instanz und können mit `self.attribute_name` oder Methoden, die sie ändern, abgerufen oder aktualisiert werden.
6. Klasseninstanzen können **miteinander interagieren**, indem Objekte als Methodenargumente übergeben und auf ihre Attribute zugegriffen wird.
7. **Vererbung** erlaubt es einer Child-Klasse, das Verhalten einer Parent-Klasse wiederzuverwenden und zu erweitern, was Code-Wiederverwendung und Spezialisierung ermöglicht.

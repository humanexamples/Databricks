## Aufgabe 1: Die `Simpson`-Klasse bauen

In diesem Abschnitt definieren Sie eine Klasse, die Mitglieder der Familie Simpson modelliert. Diese Übung festigt, wie man Instanzattribute initialisiert und Methoden definiert, die auf dem Objektzustand operieren.

### Aufgabe 1.1: Die `Simpson`-Klasse definieren

Definieren Sie eine Klasse **`Simpson`**, die Mitglieder der Simpsons-Familie repräsentiert. Die Klasse muss Folgendes enthalten:

- **Attribute** – über `__init__()` initialisiert:
  - `first_name` — der Vorname der Figur
  - `age` — das Alter der Figur
  - `favorite_food` — das Lieblingsessen der Figur

- **`simpson_summary()`** – gibt einen String im Format zurück:
  `{first_name} Simpson is {age} years old and their favorite food is {favorite_food}`
  - Beispiel: `Homer Simpson is 39 years old and their favorite food is donuts`

- **`older(other_simpson)`** – akzeptiert ein anderes `Simpson`-Objekt und gibt `True` zurück, wenn die aufrufende Instanz älter ist, sonst `False`.

> **Instanzattribute vs. Klassenattribute**
>
> Instanzattribute werden innerhalb von `__init__()` mit `self` definiert. Jedes Objekt erhält seine eigene unabhängige Kopie dieser Werte, anders als Attribute auf Klassenebene, die über alle Instanzen geteilt werden.

```python
## class Simpson
## <FILL_IN>
```

##### Aufgabe 1.1 — Die `Simpson`-Klasse definieren — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
class Simpson():
    
    def __init__(self, first_name, age, favorite_food):
        self.first_name = first_name
        self.age = age
        self.favorite_food = favorite_food
        
    def simpson_summary(self):
        return f"{self.first_name} Simpson is {self.age} years old and their favorite food is {self.favorite_food}"
        
    def older(self, other_simpson):
        return self.age > other_simpson.age
```

## Aufgabe 2: Die `Fraction`-Klasse bauen

### Aufgabe 2.1: Die Hilfsfunktion durchsehen

Die Zelle unten stellt eine eigenständige Hilfsfunktion bereit, die den größten gemeinsamen Teiler (GCF) zweier ganzer Zahlen berechnet. Sie können diese Funktion bei Bedarf aus Ihren `Fraction`-Klassenmethoden heraus aufrufen – zum Beispiel beim Kürzen eines Bruchs oder beim Berechnen eines kleinsten gemeinsamen Nenners.

```python
# Ich habe eine eigenständige Hilfsfunktion bereitgestellt, die Sie in Ihrer Implementierung aufrufen können

def greatest_common_factor(a, b):
    gcf = 1
    if a < b:
        limit = a
    else:
        limit = b
    
    for index in range(2, limit + 1):
        if (a % index == 0) and (b % index == 0):
            gcf = index
        
    return gcf
```

### Aufgabe 2.2: Die `Fraction`-Klasse definieren

Definieren Sie eine Klasse **`Fraction`** mit den folgenden öffentlichen Attributen und Methoden:

| Element | Typ | Beschreibung |
|---|---|---|
| `numerator` | Attribut | Die obere Zahl des Bruchs |
| `denominator` | Attribut | Die untere Zahl des Bruchs |
| `to_string()` | Methode | Gibt den Bruch als `"numerator / denominator"` zurück |
| `as_decimal()` | Methode | Gibt den Bruch als Gleitkommazahl zurück |
| `least_common_denominator(other)` | Methode | Gibt den LCD (kleinsten gemeinsamen Nenner) zweier Brüche zurück |
| `reduce()` | Methode | Kürzt den Bruch an Ort und Stelle auf seine einfachste Form und gibt `self` zurück |
| `is_equal(other)` | Methode | Gibt `True` zurück, wenn zwei Brüche äquivalent sind (z. B. `2/4 == 1/2`) |
| `is_less_than(other)` | Methode | Gibt `True` zurück, wenn dieser Bruch kleiner als `other` ist |
| `scale(multiplier)` | Methode | Skaliert Zähler und Nenner mit einem Multiplikator |

> **Tipp: Die Hilfsfunktion verwenden**
>
> Die oben definierte Funktion `greatest_common_factor(a, b)` kann direkt aus Ihren Klassenmethoden heraus aufgerufen werden. Verwenden Sie sie in sowohl `reduce()` als auch `least_common_denominator()`.

## least_common_denominator(other) mithilfe von greatest_common_factor implementieren
## reduce() implementieren, das den Bruch direkt kürzt und self zurückgibt
## is_equal(other) implementieren, um Dezimalwerte zu vergleichen
## is_less_than(other) implementieren, um Dezimalwerte zu vergleichen
## scale(multiplier) implementieren, um Zähler und Nenner zu multiplizieren

##### Aufgabe 2.2 — Die `Fraction`-Klasse definieren — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
class Fraction():
    def __init__(self, numerator, denominator):                     # Constructor
        self.numerator = numerator                                  # Attribute initialization
        self.denominator = denominator

    def to_string(self):                                             # Method definitions
        return f"{self.numerator} / {self.denominator}"

    def as_decimal(self):
        return self.numerator / self.denominator

    def least_common_denominator(self, other):
        # Den kleinsten gemeinsamen Nenner zweier Brüche berechnen
        a = self.denominator
        b = other.denominator
        lcd = a * b // greatest_common_factor(a, b)
        return lcd

    def reduce(self):
        # Den Bruch direkt vollständig kürzen
        gcf = greatest_common_factor(self.numerator, self.denominator)

        if self.denominator < 0:
            gcf *= -1

        self.numerator //= gcf
        self.denominator //= gcf
        return self

    def is_equal(self, other):
        # Compare equality by decimal value
        return self.as_decimal() == other.as_decimal()

    def is_less_than(self, other):
        # Compare magnitude by decimal value
        return self.as_decimal() < other.as_decimal()

    def scale(self, multiplier):
        # Zähler und Nenner mit demselben Faktor skalieren
        self.numerator *= multiplier
        self.denominator *= multiplier
```

## Aufgabe 3: Die `MixedNumber`-Klasse mit Vererbung bauen

In diesem Abschnitt verwenden Sie **Vererbung**, um die `Fraction`-Klasse zu erweitern. Vererbung erlaubt es Ihnen, eine neue Klasse zu erstellen, die alle Attribute und Methoden einer bestehenden Klasse erbt, während Verhalten hinzugefügt oder überschrieben wird. Sie bauen eine `MixedNumber`-Subklasse, die Brüche wie `1 3/4` repräsentiert – eine ganze Zahl kombiniert mit einem echten Bruch.

### Aufgabe 3.1: Die `MixedNumber`-Klasse definieren

Definieren Sie eine Klasse **`MixedNumber`**, die von `Fraction` erbt. Eine gemischte Zahl hat einen ganzzahligen Teil und einen Bruchteil (z. B. bedeutet `1 3/4` eins und drei Viertel).

Ihre Subklasse muss enthalten:

| Element | Typ | Beschreibung |
|---|---|---|
| `whole` | Attribut | Der ganzzahlige Teil der gemischten Zahl |
| `__init__(self, whole, numerator, denominator)` | Methode | Ruft das `__init__` des Parents für den Bruchteil auf und speichert `whole` |
| `to_string()` | Methode | **Überschreibt** den Parent – gibt `"whole numerator / denominator"` zurück (z. B. `"1 3 / 4"`) |
| `as_decimal()` | Methode | **Überschreibt** den Parent – gibt den ganzen Teil plus die Bruch-Dezimalzahl zurück (z. B. `1.75`) |
| `to_improper()` | Methode | Gibt ein neues `Fraction`-Objekt zurück, das den äquivalenten unechten Bruch repräsentiert (z. B. `1 3/4` → `7/4`) |

> **Vererbung & `super()`**
>
> Verwenden Sie `super().__init__(numerator, denominator)` innerhalb des `__init__` Ihrer Subklasse, um die Initialisierungslogik der Parent-Klasse wiederzuverwenden. Das stellt sicher, dass der Bruchteil genau so eingerichtet wird, wie es ein `Fraction` täte, ohne Code zu duplizieren.

> **Tipp: Umwandlung zwischen Formen**
>
> Um eine gemischte Zahl in einen unechten Bruch umzuwandeln: `improper_numerator = whole * denominator + numerator`.
> Um einen unechten Bruch in eine gemischte Zahl umzuwandeln: verwenden Sie Ganzzahldivision (`//`) für den ganzen Teil und Modulo (`%`) für den verbleibenden Zähler.

```python
## Eine Klasse MixedNumber definieren, die von Fraction erbt
## super().__init__() verwenden, um den Bruchteil zu initialisieren
## Die ganze Zahl als Instanzattribut speichern
## to_string() überschreiben, sodass der ganzzahlige Teil enthalten ist
## as_decimal() überschreiben, sodass der ganzzahlige Teil zum Dezimalwert des Bruchs addiert wird
## to_improper() implementieren, sodass ein neuer Fraction zurückgegeben wird
## <FILL_IN>
```

##### Aufgabe 3.1 — Die `MixedNumber`-Klasse definieren — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
class MixedNumber(Fraction):

    def __init__(self, whole, numerator, denominator):
        super().__init__(numerator, denominator)
        self.whole = whole

    def to_string(self):
        return f"{self.whole} {self.numerator} / {self.denominator}"

    def as_decimal(self):
        return self.whole + super().as_decimal()

    def to_improper(self):
        improper_numerator = self.whole * self.denominator + self.numerator
        return Fraction(improper_numerator, self.denominator)
```

</details>

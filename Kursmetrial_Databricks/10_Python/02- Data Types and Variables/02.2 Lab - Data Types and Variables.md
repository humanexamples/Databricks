## Aufgabe 1: Arbeiten mit Variablen und f-Strings

### Aufgabe 1.1. Variablen definieren und einen Schokoladen-String erstellen

In dieser Übung definieren Sie zwei Variablen und verwenden sie, um einen formatierten String zu konstruieren.

1. Definieren Sie eine Variable **`name`** und setzen Sie sie gleich Ihrem Namen als **String**.
2. Definieren Sie eine Variable **`num_chocolate`** und setzen Sie sie gleich der Anzahl der Schokoladentafeln, die Sie essen möchten. Dieser Wert muss eine ganze Zahl sein (also ein **Integer**).
3. Definieren Sie eine Variable **`chocolate_string`** mit f-String-Formatierung, sodass sie lautet:
   * `"<name> would like to eat <num_chocolate> bars of chocolate"`
4. Geben Sie **`chocolate_string`** aus.

```python
## name = <FILL_IN>
## num_chocolate = <FILL_IN>
## chocolate_string = <FILL_IN>

## print(<FILL_IN>)
```

##### Aufgabe 1.1 — Variablen definieren und einen Schokoladen-String erstellen — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
name = "James"
num_chocolate = 10
chocolate_string = f"{name} would like to eat {num_chocolate} bars of chocolate"

print(chocolate_string)
```

</details>

## Aufgabe 2: Arithmetik in f-Strings

### Aufgabe 2.1. Kursvariablen definieren und einen Kursinformations-String erstellen

Diese Bonusübung erweitert Ihre f-String-Fähigkeiten, indem sie einen arithmetischen Ausdruck direkt in den String einbettet.

1. Definieren Sie eine Variable **`num_students`** und setzen Sie sie gleich der Anzahl der Studierenden im Kurs als **Integer**.
2. Definieren Sie eine Variable **`num_days`** und setzen Sie sie gleich der Anzahl der Kurstage als **Integer**.
3. Definieren Sie eine Variable **`class_name`** und setzen Sie sie gleich dem Namen dieses Kurses als **String**.
4. Definieren Sie eine Variable **`course_information`** mit f-String-Formatierung, sodass sie lautet:
   * `"There are <num_students * num_days> student days in the <class_name>"`
   * **HINWEIS:** Das Produkt `num_students * num_days` muss **innerhalb** des f-String-Ausdrucks berechnet werden.
5. Geben Sie **`course_information`** aus.

```python
## num_students = <FILL_IN>
## num_days = <FILL_IN>
## class_name = <FILL_IN>
## course_information = <FILL_IN>

## print(<FILL_IN>)
```

##### Aufgabe 2.1 — Kursvariablen definieren und einen Kursinformations-String erstellen — Lösung

<details>
<summary>LÖSUNGSCODE ANZEIGEN</summary>

```python
num_students = 16
num_days = 2
class_name = "introduction-to-python-for-data-science-and-data-engineering"
course_information = f"There are {num_students * num_days} student days in the {class_name}"

print(course_information)
```

</details>
